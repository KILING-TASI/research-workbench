# 北交所资金与收益情景

用于回答“这笔资金在不同配售和价格假设下会怎样”“费用占多少”“同日是否撞车”。不输出申购指令、最优金额或首日卖点，不恢复此前取消的预测模型优化。

## 使用入口

主包根目录运行：

```bash
python scripts/research_topics.py bjx scenarios -- INPUT.json --out-dir NEW_DIRECTORY
```

输出输入副本、结果、自然语言HTML/Markdown及报告清单，可用主包research_results.py在指定父目录找回。AI从用户问题组织参数，不要求用户填写JSON。已有公告事实优先复用；本入口的计算成功不认证发行公告。

输入allocation沿用[获配与现金流](allocation-cash.md)：代码、发行价、申购上限、预算、申购日、退款实际可用日、卖出结算日、机会/融资成本及费用。maxShares用该只发行公告值，不从最终网上股数乘5%反推。退款和结算日期不默认推定T+2或固定3天。

scenarios为1至50项，每项id、ratePct（百分数）、gainPct（百分数）、rateBasis、gainBasis。配售率和价格假设成对输入，不将两边独立抽样。可选probability必须每项都有且合计1，probabilityBasis必填；没有权重仅做情景并列，不计算期望或破发概率。输入权重不是自动校准的预测概率。

费用新增transferFeePct，与commissionPct、minimumCommission、taxPct及slippagePct分列。所有费率依实际历史生效日期及券商账单核对，未填的零假设不是免税。金额和费用均为人民币，百分数字段0.05表示0.05%。融资成本与机会成本分列，按资金来源避免经济口径重复。

## 报告判断

先解释比例整手是否跨过百股阶梯，以及扣费后收益是否仍正，再展示逐项成本。低于门槛仍保留余股未知；不写“一股拿不到”。加权汇总只覆盖比例整手情景，不含未知余股；正收益可能被低估，破发损失也可能被低估，不作为损失界。

已有多只资金冲突使用issuance_research.py cash或cash_repo_ledger.py，默认同日申购先于释放资金；到账时间有证据才允许同日再用。检查指定方案，不自动选标的或顶格。用户现金账不能推导全市场可用资金。

## 对扩展设计的纠正

|需要收紧的表述|采用口径|
|---|---|
|碎股线必然高于比例百股门槛，低于门槛必然零获配|余股按数量与时间排序；两个阈值不存在普遍固定大小关系|
|低于p90意味着90%概率不中|若门槛分布已校准，金额对应的是该分布累计概率；低于p90只说明未达到90%覆盖，不说明失败率为90%|
|未中净收益为零|毛获配收益可能零，机会/融资成本仍可能为负贡献|
|比例门槛之上股数与金额成正比|比例整手有向下取整阶梯；不按连续直线近似实际获配|
|破发概率不进入期望|负收益情景必须进入所声明联合权重的汇总，同时单列风险|
|户均金额=全市场可用资金×参与率|总参与资金除以参与户数才是户均金额；参与户数不必单调增长|
|同日冻结资金必然负相关|共同资金冲击可能形成正相关，固定总量下的分配约束不等于无条件负相关|
|公告可确定全市场资金潮汐|公告不覆盖闲置资金、外部流入、券商可用时点；仅用户明示现金账可计算|
|报童解必然约均值加2.2个标准差|依分布、收益和成本假设变化；离散申购、多个整手、未知余股及负收益未验证，不启用推荐|
|2026年65只与行业收益数字可直接作为参数|用户材料数字未逐项核原文，不能写入默认参数或声称完整历史验收|

比例配售与不足百股余股处理参见[北交所证券发行与承销管理细则](https://www.bse.cn/fxrz_list/200025384.html)，实际发行以对应公告、回拨后数量及结果为准。公开网页的抓取成功不替代完整条文和当前适用版本核查。

## 来源复盘与后续边界

复用prediction_review.py freeze/replay/review流程，scorecard额外汇总已保存首次冻结、实际率原文数值匹配的复盘记录，输出有符号偏差、MAE、RMSE、样本标准差和样本数。历史回放不计入，少于5项只描述小样本，不融合。哈希和本地时间不是外部可信时间戳。

逆方差融合、资金预测、安全垫、分钟线卖出优化、发行节奏预测尚未启用。后续需事前冻结数据、来源相关性、规则版本及滚动前推证据；相同历史上挑选最佳策略再验收不能证实改善。不新增定时扫描、后台推送或交易执行。

报告分列扣除机会成本后的声明预算收益率，以及未扣机会成本的资金日简单年化。前者包含闲置预算稀释但不计闲置现金利息；后者以分段金额×自然日为分母，不等于账户全年或复利收益。卖出费用数学精算未包含券商分项舍入，金额不是账单认证。

余股敏感性：有比例零头且申购股数允许时，报告并列仅比例部分和假设额外100股两条结果，重新计算留存本金、卖出费用、融资与机会成本。它们不是统计区间或最坏损失界，也不给余股概率；破发时额外获配会增加损失。加权汇总仍只针对比例部分，不把额外百股混入默认期望。
