# 申购与通用回购逐笔现金账

入口：scripts/cash_repo_ledger.py 输入.json --out 新文件.json。使用Decimal计算。支持总本金、观察起止日、issues与repos；所有日期由有依据的输入给定，不以自然日加一冒充交易日历。

issues每项：id/applyDate/refundAvailableDate/saleAvailableDate/subscriptionFunds/allocatedPrincipal/saleNetProceeds，可选announcedRefundDate。公告退款日与账户可用日分别保存，不能把退款先于公告日期。卖出净收入由已披露事实或明确假设提供。

repos每项：id/tradeDate/firstSettlementDate/maturitySettlementDate/availableDate/principal/annualRatePct/commission/dateBasis。若可用日早于到期交收日，须声明earlyAvailabilityEvidence，供AI结合原文进一步核验；声明不是程序认证。按首次交收日含、到期交收日不含的自然日天数计算利息，年基数365，佣金按输入扣除，必须明确填写commission，包括显式的零费用假设；缺失或空值不能按零费用计算净收益。

计息规则来源：[上交所通用回购指引](https://www.sse.com.cn/lawandrules/sselawsrules2025/bond/trading/currency/c/c_20250606_10781048.shtml)。实际占款天数与名义品种天数不可混用。

同日默认先申购扣款、再回购占款、最后到账释放。输出每笔收支、逐日开闭余额、日内最低现金、额外本金缺口与期末尚未释放事件。现金为负时标冲突，不自动借款，不认为订单可执行。逐笔输入可以核查资金复用，但没有真实账户和交易日历时仅为情景，不称真实账户验收。

简化闲置资金比例模型与逐笔现金账分别展示，不能混为同一结果。逐笔账核查明确日期、佣金、同日占款与期末未结算；这些检查不证明任意市场规则和券商到账时点已核验。

## 页面入口
打新收益 → 逐笔资金时间账，导入资金计划后自动计算。可下载页面内纯假设示例，填入公告或账户确认的日期与金额。网页金额精确到分、利率最多六位小数；独立 Python 支持 Decimal。页面与脚本已交叉验证正常、缺口、同日占款、未结算和半分舍入样本。逐笔结果不替换上方理想化年化；不代表已核验账户流水。

## 自动历史申购现金计划
AI根据用户本金及区间调用 `scripts/generate_cash_plan.py --data assets/data.json --overlays assets/calendar-verified-fields.json --calendar assets/bse-trading-calendar-2026.json --capital 元 --start YYYY-MM-DD --end YYYY-MM-DD --out-dir 新目录`，输出plan.json、ledger.json和excluded.json。用户不必手写JSON；plan可直接导入页面逐笔账。依次用可用现金和申购上限生成整手申购，退款当天先申购后到账，卖出按下一交易日可用情景，公告非交易日退款顺延。仅覆盖 supplied calendar 年份，区间不超过缓存日期，缺数据及资金不足逐只排除。默认不计费用、首日收盘卖出，仅用实际率历史回放，严禁当作事前预测。通用回购需另输入真实或明确假设的逐笔日期，不把理想化利息加进本计划。1000万、2026年初至10月3日实跑65样本、51参与、14排除，153笔事件与浏览器引擎全部余额一致；账户可用日未认证。

页面逐笔资金时间账现支持「按当前本金与年份生成资金账」，沿用打新收益输入，直接显示逐笔结果及排除原因。仅2026已核验日历，其他年份拒绝自动计划而保留独立导入。浏览器用BigInt分币运算，三个真实资金档位（50/1000/2000万）全部事件与Python Decimal计划对照一致。自动计划单独按零费用历史情景，不混用上方费用设置和理想化回购利息。已验证函数计算和代码入口，不等于真实浏览器视觉或交互验收。

## 自动闲钱回购固定结算情景
页面「加入通用回购排程情景」沿用本金、年份、利率和利用率。独立命令generate_repo_scenario.py读取基础plan及回购市场交易日历，可显式输入每笔佣金与资金档位。固定日期假设为交易后下一交易日首次结算，再下一交易日到期并可用，**不是认证的一日回购产品规则**。利息按声明结算区间实际自然日/365逐笔计提；金额档位默认1000元只是情景参数。当天先申购和回购占款再释放，回购到款不晚于观察期且必须早于下一申购日；不合条件不排程，出现未来资金缺口撤销候选笔。基础申购量固定，不用回购利息重新放大申购量；已结算利息可以进入后续回购本金。此情景与上方每日闲钱简单计息不同，不宣称增厚幅度保证实现。1000万实跑57笔回购、267笔现金事件跨引擎全部日期与余额一致；默认1.5%/80%/零佣金情景增加期末现金5536.77元，不是未来收益或真实账户结果。8项相关单元测试通过，真实浏览器仍未验收。

历史年份核验缺口（2026-10-03）：2025北交所官方检索命中全年公告，但直接正文打开重定向循环；2022—2024仅取得媒体/法规库线索，没有取得可复核北交所原始全年材料。不得标记已核验。页面切换年份时在年化结果上方明确自然日旧假设和资金复用偏差，2026则说明交易日历情景也不是账户到账。切换警示逻辑已测试，不是浏览器视觉认证。

年收益回放与逐笔账：已核验日历年份内，公告退款日落在休市期时顺延至下一交易日情景，同日申购仍先于资金释放。零费用下三档真实缓存毛收益已对齐逐笔账；年末统计截止按观察期收口。费用、理想闲置利息与逐笔回购各有明确假设，真实账户可用日未核验。

整手比例取整：年收益回放申购股数、比例获配股数改用整数分及十进制有理数计算，不再添加浮点epsilon抬升门槛。输入本金须精确到分并处于页面安全范围；接近但未达到百股门槛的结果不得向上补足。
