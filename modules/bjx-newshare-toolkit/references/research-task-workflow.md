# 研究任务接续

页面研究记录保存在浏览器。用户导出“投研研究记录.json”后，Skill 使用内置 Python 运行 `scripts/research_tasks.py import <导出文件>`，落盘到技能工作目录的 `research/tasks/`。下载文件不是已经入库；必须报告实际导入结果。不要自动读取用户未指定的下载文件。

执行入口：

- `list`：列出任务、复查日期、未完成步骤。
- `show <id>`：读取首次冻结依据、后续导入版本及执行日志。
- `record <id> --step <步骤名称> --result <核验结果> --evidence <来源或本地证据位置>`：记录进展；未加 `--complete` 时步骤仍待办。
- 已核实后加 `--complete`：完成指定步骤，必须附证据。工具检查证据非空，但真实性由执行 Skill 核验，不能用占位文本完成。
- `export <文件>`：备份全部任务档案。该档案供 Skill 使用，不是页面研究记录导入格式。

按任务选择所属模块。先核对来源和字段口径，再检查所属期、发布日期、抓取时间、历史覆盖与缺口，随后核验暂定判断及反方证据，最后记录结论和下次复查安排。首次 sourceRecord 不覆盖；再次导入同ID只新增版本。当前页面缓存比较属于离线检查，不是联网刷新或公告核验。缺证据继续待办，不能依据任务执行成功宣称研究结论正确。

财务事实需保留证券代码、报表期、币种单位、合并范围、累计或单季口径及公告页码/原文片段；第三方汇总值未逐项核对前不能升级为官方事实。历史研究仅使用当时可得信息，未来结果只用于核验。刷新某模块需遵循用户当前范围；已暂停的北交所模型优化不因任务接续自动恢复。

任务文件包含研究笔记和冻结数据，仅本地保存。页面与磁盘没有自动双向同步；修改磁盘任务不会自动修改浏览器记录。继续研究时以文件档案读取未完成步骤，并将新证据和实际结果写入执行日志。
