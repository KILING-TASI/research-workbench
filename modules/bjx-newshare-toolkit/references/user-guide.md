# 北交所新股研究助手使用说明

直接输入股票代码或问题即可使用，无需打开工作台。需要日历、卡片或收益曲线时，可以使用工作台查看。

## 可以做什么

| 功能 | 输入 | 返回内容 |
| --- | --- | --- |
| 新股日历 | 公司名称、代码或日期范围 | 申购、退款、结果公告及上市日期，发行价格、市盈率、申购上限和公告来源 |
| 新股测算 | 新股代码、预算及配售率条件 | 比例百股资金参考、整手获配情景、资金档位和上限可达性 |
| 打新收益 | 本金、研究区间 | 按历史首日涨幅计算的损益、资金占用和约合年化，可加入通用回购情景 |
| 公告核对 | 标的、公告或PDF | 关键字段、页码、来源、口径差异及更正内容 |
| 公司研究 | 新股代码或招股书 | 财务信息、同行估值对比及业务和财务风险 |
| 多新股资金分析 | 多只新股及总预算 | 冻结时间重叠、现金占用和资金缺口 |
| 研究复盘 | 已保存研究资料和实际结果 | 输入变化、结果偏差及可复查依据 |

## 直接提问

- “查一下这只新股的申购日期和发行市盈率。”
- “预算100万元，这只新股的百股资金参考是多少？”
- “按过去一年的首日涨幅，比较100万、500万、1000万资金的历史收益。”
- “这几只新股申购时间重叠，资金会占用多久？”
- “核对这份发行公告，有没有更正影响价格或申购上限？”

只需提供问题涉及的代码、金额或区间；缺少必要信息时会提示补充。

## 数据与结果说明

日历显示数据更新时间。新股数据可按需刷新，安装后不会自行后台更新；联网失败时保留原数据，并说明其时间。公告按当前问题核对必要字段，历史公告在回放或发现异常时按需查证。

结果区分公告依据、第三方数据、假设及待核验信息。缺少依据的字段不会用0代替。扫描PDF可补充文本供核对；不能直接提取时需查看原页。部分公司资料不完整时，分析会列明缺项。

百股资金是给定配售率及规则下的参考，不保证获配；粗精度公告数据无法确定精确临界档位。现金释放日期依所提供日期或明确情景计算。历史首日收盘价测算不等于实际成交，费用和通用回购利率按所列假设计入。

所有内容仅作客观研究与条件测算，不执行申购或交易，不构成投资建议。存在本金损失风险，历史表现和情景结果不代表未来收益。
