# 数据与测算口径

## 模型验证

项目模型验证入口滚动验证最近60只有效发行；独立 fetch 不运行模型。预测使用申购日前已上市样本，窗口在此前训练目标中选取，历史不足时回退20只，剔除不足选定窗口的记录；目标股实际率仅用于事后计算真实条件门槛。误差=(预测资金/实际资金−1)×100%，负数表示资金低估。展示平均、中位及P90绝对百分比误差和低估比例；包含超上限的理论门槛并单独记录其可达性。

历史重建数据可能有修订和遗漏，不等同于冻结的原始事前预测。自动更新会在申购日前或当日首次发现新股时保存带时间戳的三档预测，后续独立核验；申购当日捕获不保证早于当日下单时间。历史重建指标与冻结验证分开统计。三档分位为P75/P50/P25，样本窗口由过去的共同训练目标选择；不能使用目标自身或未来结果选窗。完整模型刷新在授权范围内执行，暂停不自动恢复。

## 百股资金

设申购单位 u=100、目标 t=100、最终配售比例 r、发行价 p，申购股数 q：

- 比例配售整手下限 = u × floor(q×r/u)。
- 百股门槛 q = u × ceil(t/(u×r))，资金 = q×p。
- 以目标申购日前（或今天之前）已上市且有实际配售率的自适应选定数量的北交所新股形成窗口，排除目标自身和2021-11-15以前发行。乐观=P75、基准=P50、悲观=P25，按(n−1)×分位点线性插值。样本不足时披露实际数量；当前精简页面不提供手动覆盖。配售率越低资金门槛越高。不能仅多备现金却不增加有效申购股数。
- q 超过公告上限时不可达；配售率为空时可输入假设，0表示无法配售。
- 连续参考 q×r 只反映未取整比例，不是零股获配概率。

## 收益

单股：q=min(floor(B/(p×100))×100, floor(maxShares/100)×100)，且满足最低申购数量。获配下限 a=100×floor(q×r/100)。费用模型为卖出成交额×费率（用户综合费率），净收益=a×p×涨幅−a×p×(1+涨幅)×费率。不含融资成本、最低佣金、滑点。

年度事后回放：按申购日与代码排序，单股使用当时所有可用本金直到上限。退款日释放未获配金额，上市次日（保守按自然日）释放认购本金；净收益累计独立记录、不再投入，亏损减少本金。相同日期先释放资金再申购。缺少价格/上限/实际配售率/退款日/上市日/首日涨幅、日期矛盾或尚未完成上市的记录不纳入，显示剔除数。期末还未释放的本金继续占用。

年度累计回报=净收益/初始资金；简单年化=累计回报×365/观察期自然日。观察期为所选年份1月1日至该年12月31日或今天（北京时间），完整闰年使用366天。不是复利收益或XIRR。单股显示冻结资金占用年化和全账户年化，两者分母分别为申购金额、账户总资金；占用期为申购至上市次日，不用退款期代替全部持股期。

回放使用已知最终配售率和首日收盘涨幅，存在事后信息；同日优先顺序会影响收益。图表仅为这一策略的情景结果，不保证收益。基准涨幅用已上市历史样本算术平均，缺失率假设用历史配售率中位数；明确显示样本数，未来情景仍需用户判断。


公告来源优先交易所官网、巨潮资讯原文，第三方仅作补充。刷新自动通过巨潮公开检索接口，优先按证券代码定位，名称仅作发行人精确匹配回退、申购日前30天至后90天检索发行公告、招股说明书、发行结果、上市公告等，保留原文链接、标题、日期及检索时间；近期发行每次刷新，历史公告首次补全后缓存。接口失败保留旧公告并标注未更新。交易所原文由 Skill 检索核实后写入 records[].announcements（title/date/source/url），优先于巨潮链接；不得猜测PDF地址。公告来源升级不代表第三方结构化字段已核验，发行价、申购上限、配售率须读原文逐项核对后才可标记官方核验。
