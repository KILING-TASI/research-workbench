# 投研 · 北交所打新

工作台同时接入独立的ETF行业轮动技能。仅刷新北交所时使用 `scripts/etf_embed.py` 保留assets/etf-*资源，不清空ETF快照或重复套用旧页面改造脚本。ETF数据与评分由兄弟技能etf-sector-rotation管理，不能混入北交所配售率样本与预测档案。

使用 `assets/workbench.html` 交付可直接打开的工作台。用户要求更新数据或进入申购前分析时，由 Skill 侧刷新：通过 `load_workspace_dependencies` 获取内置 Python，运行 `scripts/toolkit.py refresh`；不要要求用户安装环境。更新后重开工作台。需要在页面内刷新时，可由 Skill 启动 `scripts/toolkit.py serve`，打开 http://127.0.0.1:8765 。本地文件模式按钮提供“请在 Codex 请求刷新”的提示，不能伪称已联网更新。失败保留原快照并显示样本未更新及原抓取时间。

发行快照保存后自动调用 `scripts/refresh_model_research.py`，依次重算缓存公告核验、研究因子及跨年对照。检查 `assets/模型研究刷新状态.json` 的输入哈希、逐步状态和时间；失败或未执行步骤不能称为最新。该流程不自动补下载缺失公告、不刷新市场/宏观数据源、不部署研究候选。历史回测改善仍需独立未来冻结确认。

刷新自动生成 `assets/北交所新股配售率样本.csv`。三档用目标申购日前已上市且有有效实际配售率的自适应窗口北交所新股；候选8/12/20/30/40/60只，以目标申购前已上市样本的最近40个共同训练目标（至少12个）比较基准百股资金MAPE，选择误差最小窗口；不足时退回20只。排除目标自身与精选层时期。乐观P75、基准P50、悲观P25，线性插值。当前精简页面不提供窗口与配售率手动覆盖控件。

当前资金视图只有选择新股这一输入，自动显示顶格申购资金与乐观/基准/悲观三档百股资金；已公布配售率的实际门槛另以一行参考文字显示。单位放在标题，测算口径和来源折叠显示。用户已移除账户资金输入及对比条、情景手动控件、顶格收益、参与决策依据和市场观点卡片。保留其他独立视图需要的资金输入，后续改动遵循这一界面范围。

每次刷新自动调用 `scripts/validate_model.js`，生成 `assets/模型验证.json` 并嵌入页面。最近60只有效新股逐只使用申购日前已上市的自适应历史窗口样本，比较预测与实际百股资金，报告有符号误差、平均/中位/P90绝对百分比误差和资金低估比例。历史不足选定窗口剔除；当前数据库重建不是原始事前预测，披露修订和覆盖偏差。申购前发现的新股冻结三档预测于快照 predictionArchive，后续刷新用实际率核验，不能覆盖旧预测。刷新更新数据与分位数，每个验证目标只用该目标申购前已上市的训练目标选窗；不得使用当前目标或未来结果调参，不宣称未来误差最小或保证获配。

先读取 [测算与数据口径](../methodology.md)。每次分析核实北交所现行规则和个股发行公告；第三方快照不能替代公告。保留数据抓取时间、来源、缺失字段和样本覆盖范围。刷新失败不能宣称已获取最新数据。

“稳获百股”仅指给定最终配售率下的比例配售整手下限。未知最终配售率时输出情景区间，不承诺获配概率。不得将北交所配售率套入抽签二项分布，也不得假定零股必然获配。超过申购上限时明确显示无法通过比例配售达到目标。

资金档位分析同时输出按比例取整结果和连续比例参考；连续值不是实际获配预期。年度回测使用退款及上市事件模拟可用现金，同日按代码顺序申购、不分散、收益不再投资；披露这一策略。历史实际配售率和首日收益仅用于事后回放，不称为无前视偏差的策略测试。

用户询问是否值得参与时，列出配售率和涨幅假设、资金占用、费用、破发情景及数据缺口，提供条件化判断。不能只依据历史平均涨幅给出参与结论。

修改计算后运行 `node scripts/test_engine.js` 和 skill-creator 的技能验证器；用浏览器核实选择股票、修改资金、日期筛选及数据刷新/失败提示。不要把演示数据混入真实样本。


公告来源优先交易所官网、巨潮资讯原文，第三方仅作补充。刷新自动通过巨潮公开检索接口，按发行人名称精确匹配、申购日前30天至后90天检索发行公告、招股说明书、发行结果、上市公告等，保留原文链接、标题、日期及检索时间；近期发行每次刷新，历史公告首次补全后缓存。接口失败保留旧公告并标注未更新。交易所原文由 Skill 检索核实后写入 records[].announcements（title/date/source/url），优先于巨潮链接；不得猜测PDF地址。公告来源升级不代表第三方结构化字段已核验，发行价、申购上限、配售率须读原文逐项核对后才可标记官方核验。

## 研究任务接续

用户需要保存研究依据、继续核验或复查已有研究时，读取 [研究任务接续](../research-task-workflow.md)。使用 `scripts/research_tasks.py` 将页面导出记录保存为文件任务，保留首次依据、待办步骤、证据及执行日志。页面缓存检查不等于联网更新；已暂停研究不自动恢复。
