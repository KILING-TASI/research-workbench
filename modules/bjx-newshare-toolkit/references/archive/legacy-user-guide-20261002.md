# 北交所新股打新助手

双击 `assets/workbench.html` 可离线使用内置真实快照。输入资金、选择新股，调整配售率和涨幅即可看到情景结果。年度回放使用历史实际数据，不受单股假设输入影响。

## 更新数据

使用 Codex 时，直接说“更新北交所申购数据和该股市场观点”，Skill 会使用内置运行环境刷新，使用者无需安装 Python。下面命令供独立部署者使用。

需要 Python 3.10 或更新版本，不依赖第三方库。在技能包目录打开终端：

```
python scripts/toolkit.py refresh
```

重新打开工作台即可加载新快照。要使用页面中的“刷新公开数据”按钮：

```
python scripts/toolkit.py serve
```

浏览器打开 http://127.0.0.1:8765 ，保持终端运行。服务只绑定本机。刷新失败保留旧数据。静态部署仅上传 `assets/workbench.html` 即可使用计算功能；刷新需要重新生成并上传文件，或通过页面导入导出的标准 JSON。

## 结果如何理解

- 百股资金是给定最终配售率下的整手比例配售门槛，不保证未知配售率或零股排序结果。
- 零股排序缺乏全体申购数据，无法计算真实“预期中签数量”；工作台给出整手股数和未取整比例参考，后者不能当成实际账户预期。
- 按整手比例模型，小资金可能显示零收益；真实零股获配可能增加收益，不能把模型零值解释为真实一定不中。
- 年度按固定本金进行事后回放：同日按代码排序、使用可用资金、退款后复用本金，上市次日释放认购本金；收益不复投。已公告但尚未完成上市的记录剔除。
- 2020年至2021年部分样本属于新三板精选层前身时期，适合历史参考，不能与当前北交所规则无差别混用。
- 来源为第三方公开数据；未逐股核验全部公告。公告核对入口和北交所官方链接已提供。

## 稳获百股资金测算

进入“稳获百股资金测算”后，一屏显示顶格资金、条件百股门槛、账户资金及缺口结论。三档配售率取申购前已上市最近20只样本的P75/P50/P25，窗口可改，每档可手动覆盖；“恢复样本值”会清除覆盖。已公布的目标自身实际配售率不进入历史窗口，可手动输入复盘。

资金对比条右端固定为顶格资金；账户或百股门槛超出时明确标注，不扩大刻度。绿色仅代表该配售率假设下资金够用，不承诺未知最终配售率或零股排序结果。

资金页专注资金门槛判断。顶格资金作为申购上限参照，页面不再提供顶格收益、破发收益、参与决策依据或市场观点卡片。收益分析在独立“收益对比”视图中查看。

`assets/北交所新股配售率样本.csv` 随刷新自动更新，含有效申购金额。页面只在测算视图显示样本抓取时间；刷新失败显示“样本未更新”及最后更新时间。

Skill 入口是 `SKILL.md`，完整测算口径见 `references/methodology.md`。要让其他 Codex 环境发现此技能，将整个 `bjx-newshare-toolkit` 文件夹放到该环境的 `.codex/skills` 目录。


公告来源优先交易所官网、巨潮资讯原文，第三方仅作补充。刷新自动通过巨潮公开检索接口，按发行人名称精确匹配、申购日前30天至后90天检索发行公告、招股说明书、发行结果、上市公告等，保留原文链接、标题、日期及检索时间；近期发行每次刷新，历史公告首次补全后缓存。接口失败保留旧公告并标注未更新。交易所原文由 Skill 检索核实后写入 records[].announcements（title/date/source/url），优先于巨潮链接；不得猜测PDF地址。公告来源升级不代表第三方结构化字段已核验，发行价、申购上限、配售率须读原文逐项核对后才可标记官方核验。
## ETF 行业轮动

侧栏“ETF行业轮动”已接入，沿用同一界面。选择周期、调整权重或行业观察池，查看评分、行业详情、ETF候选及配置图表；支持CSV与图片导出。当前8个行业、16只ETF候选，宏观周期手动选择，尚未联动宏观/基金择优模块。行情、财报和规模日期分别显示；备用数据、北向持仓变化缺失及实际跟踪误差缺失均有说明。权重设置与记录保存在当前浏览器。

数据由独立技能etf-sector-rotation刷新并同步到此页面。本地文件可离线查看，刷新需在Codex请求或启动本机服务。默认收盘后16:30（北京时间，工作日）更新与留存快照；节假日不伪造当日行情。页面刷新失败保留原快照。政策事件由Skill侧核实原文再入库，按7天衰减，有限检索不等于完整新闻覆盖。


工作台一级入口为“ETF能力域”，下设ETF行业轮动（现有已接入）、ETF择优（待开发）、ETF组合配置（待开发）。三个入口独立显示，切换待开发入口时隐藏行业轮动内容。后续刷新保留这一导航层级。
