# 北交所年度收益情景

输入客户资金规模，结合明确声明的三档市场参数，输出年度累计净收益区间、收益构成、敏感性、替代用途和阶段性重新评估提示。先核权限声明，再计算；不要求用户填写JSON，由AI准备输入。

## 调用和示例

主包根目录调用：
```text
python scripts/research_topics.py bjx annual -- modules/bjx-newshare-toolkit/assets/example-annual-yield.json --capital 10000000 --out-dir NEW_DIRECTORY
```
示例是教学参数，不是客户权限认证或市场预测。实际计算须询问或取得权限、可用资金、发行价、配售假设、卖出涨幅、年度参与只数、费用和资金日期；没有依据不得沿用教学值。输出包括中文Markdown/HTML、输入、结果与文件清单。权限未确认只输出缺项，不计算收益。

用户追问“换成1250万元呢”，可复用已找到的年度报告：
```text
python scripts/bjx_annual_followup.py --continue-from PREVIOUS_REPORT_DIRECTORY --capital 12500000 --out-dir NEW_DIRECTORY
```
只改变明确给出的客户资金规模，重新核权限与可用资金；保留旧输入，另存调整说明。所有市场、费用、在途资金及权限声明沿用，不能称自动更新。已有结果找回使用主包报告检索入口；选择年度情景目录，不能拿其他研究输入混用。

## 输入与单位

完整结构见随包示例。`s_capital`、`s_in_transit`、`p0`、`a_star`、`a_max`为人民币元；`c_annual`、`r`、`sigma_pct`、配售率与比例费用均为小数比例：0.02表示2%，与旧获配入口的百分数单位不同。佣金最低额为元。发行价、中心百股资金、配售率至少给两项；三项同时给出须一致。每档必须注明参数依据。

## 前置、成本与金额选择

- 权限、风险和测试为输入声明，不查询或认证真实账户。50万元资产及24个月经历按规则核对；科创板权限仅影响相应程序条件，不能推断北交所权限已开通。C4/80分按本方案券商条件检查，不宣传为所有券商通用法律门槛。同一身份重复账户拦截；使用匿名身份键，不收身份证号码。
- 金额上限取可用资金与申购上限较小者，按100股金额取整。比例获配模型未计余股，不能将零比例整手解释为实际无获配。
- 在零、上限、整手中心门槛和损失方程代理门槛构成的有限候选集中选净收益较高者；不固定μ+2.2σ，不证明全局最优，也不作为账户交易指令。
- 逆回购成本逐个交易日按首次与到期结算日期之间的自然日计息。内置2026中国交易日历，调休周末不开市；其他年份或跨年不猜日期。普通周代表窗口周一/二/五2天、周三/四4天，节假日逐笔算。每日资金可复用仍需券商结算声明。
- 比例佣金与最低佣金取大后按获配概率加权；退款后获配本金成本按卖出资金可用日期计算。未提供该日期必须提示成本不完整。

## G0–G4交付与降级

报告必须有收益构成、假设、敏感性、口径比较、免责。并排列出替代用途，但不同资产的波动与流动性不等价；缺可比数据留空。不硬编码2.62%、1000万元分界、零成本或固定宽基波动。

最近五只破发占比仅在样本声明完整且无缺失时判断；配售率变化须有约三个月前后同口径来源。触发用户阈值时输出阶段性暂停方案采用与重新评估提示；未触发不代表安全。重启需重新观察破发、可比收益、配售和完整资料。

发行要素缺失→手工假设；发行结果缺失→情景未回填；上市表现缺失→排除该只，不填零。日历不会联网兜底。当前入口不自动抓取T-2/T+2公告，不把声明来源称独立核验。

年度数值为代表单次净收益×声明参与只数÷全部客户资金，不复利、不验证全年度窗口重叠，不能称已校准未来年化。与券商报告应逐项对齐取整、费用、分母、参与范围和资金日，无通用折减系数。E1–E5预测扩展、分钟卖出与后台任务不在本次范围。

新增期望手数、标准差与比例零整手概率；假设与公式纠正见[补丁核对](../../../references/engine-patch-review.md)。
