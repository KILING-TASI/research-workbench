# 投研 · 宏观研究

维护基钦、朱格拉、库兹涅茨、康德拉季耶夫四周期的指标库。指标定义、单位和数据源以 assets/catalog.json 为准。

## 独立使用

读 [独立安装指南](references/standalone-install.md)，使用可用的 Python 从主包根目录执行 `python scripts/research_topics.py macro standalone -- --data-dir <用户目录>` 初始化空指标库；加 --refresh 获取已接入官方公告观测。不导入安装者的历史缓存。失败保留旧值与原时间并标记错误；未接入项留空。

核对数据所属期、官方发布日期、抓取时间及单位。抓取时间不能代替官方发布日期；同比/累计同比、存量/增量、库存金额/扩散指数等不混接。来源入口登记不等于已取到数据，已取历史不等于足以判断周期。

## 研究与工作台

四周期独立判断。当前阶段未通过数据与历史拐点验证时留空，显示依据、历史覆盖和缺口。不用固定55/20/9/3.5年正弦波推算确定谷底，不输出未经校准的可靠度百分比或主观冲击分数。

价格与增长状态独立展示，不替代四周期定年。现有价格阈值是研究规则，需同月对齐、连续两个月确认；不称官方阶段标准。政策流动性仅辅助提示，不直接改变阶段。

完整工作台需齐全资产与同级模块后才运行 build.py。四周期卡片单列，可展开数据依据；投资期限改变研究解释，不自动生成配置权重。市场雷达与配置数值仍需同日历史及有效性验证，缺数据不绘制定位。投教知识单独组织，事实、解释和研究推理分开。

研究保存首次依据，复查对比当前快照，不冒充已联网核验。没有用户授权不创建定时刷新，宏观结果不会自动改变ETF研究参数。

## 投研输出与场景验收

按当前用户约定，采用客观分析模式，不直接推荐买卖、承诺收益或预测价格涨跌。具体投资分析前置相关风险，区分已核验、推理与缺项；验收按[场景规范](references/research-scenario-acceptance.md)及其177项用例执行，未执行不报通过。

分发、商业部署或分享含原文附件的研究包前，查阅[第三方许可说明](references/third-party-notices.md)。
