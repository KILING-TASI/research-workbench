# 投研研究助手：功能说明

**文档版本：1.47 · 更新日期：2026-10-08 · 状态：现行总纲**

面向个人投资者与买方研究人员。直接提出问题即可使用，工作台可选。第一次阅读先看下表；需要参数或详细口径时，再打开[方法与参数索引](capability-reference-index.md)。

这里的ETF指在交易所买卖的基金。其他专业词语在首次出现时解释，也可查[术语表](research-glossary.md)。版本沿革和各份说明的分工见[文档索引](documentation-status.md)。

说明按三个层次阅读：**研究场景**回答“研究什么”；**共用能力**提供资料核验、事件解读、档案与导出；**交付形式**包括查询结果、比较、诊断、深度报告与一页纸。脚本和代码目录仅在实际调用时查阅。

## 你可以用它研究什么

| 场景 | 可以这样问 | 你会得到 |
|---|---|---|
| 标的查询与候选筛选 | 哪些基金符合我的筛选条件？ | 候选名单、筛选理由与缺失字段 |
| 基金与ETF产品研究 | 这两只产品有什么差异？ | 历史表现、持仓、经理资料和费用对照 |
| 持仓与组合研究 | 我是否重复押注同一行业？ | 已知底层暴露、集中度和收益风险贡献 |
| 公司与行业研究 | 利润增长有没有现金支持？ | 财务底稿、经营解释、同行比较和估值情景 |
| 宏观与跨资产观察 | 指标怎样变化，资产同期表现如何？ | 官方观测、共同历史窗口与解释依据 |
| 北交所新股研究 | 参考百股资金是多少，会不会占用冲突？ | 配售情景测算、公告依据和现金时间账 |

## 1. 标的查询与候选筛选

**能做什么**

- 根据代码、名称或主题查找候选，确认证券名称、市场、币种及份额类别。
- 查询已有净值、价格、规模、经理、费率、资产配置和持有人资料。
- 按收益、回撤、波动率、夏普比率（单位风险对应的超额收益）等条件筛选，保存观察池并主动运行评分或批量诊断。
- 在已取得的持仓报告范围内，反查哪些基金持有某只股票或某行业。

**交付示例**：“在我的观察池里，筛选近三年回撤低于20%、夏普大于1.2的基金，缺数据的单列。”

> **使用条件**：先明确候选范围、时间区间和字段来源。名称含有某主题只是检索线索，实际主题暴露要核对持仓。缺值单列，不视为通过；结果不代表全市场排名。

[查询与筛选的详细入口](query-screen.md)

## 2. 基金与ETF产品研究

**能做什么**

- 先检查净值日期与跳变线索，保留相邻观测起止；缺产品适用日历时不宣称日期完整。
- 在共同历史区间比较收益、回撤、波动和相关性；有基准数据时，展示相对表现；声明基准适用日期后，比较入口拒绝跨越该版本的有效区间。
- 核对机构与个人持有份额、期末份额分母和期间份额变动，区分盈利人数、基金收益与现金流。
- 汇总已取得的经理任职资料和年报观点，结合任期解释产品表现。
- 比较A/C份额成本，计算费用相当的持有期限；回放固定金额或份额的定投，列出逐期投入与结果。
- 分别分析ETF跟踪的指数、产品本身及其在组合中的作用，观察成分集中度和跟踪质量。
- 用“两期基金份额差 × 期末净值”估算份额变化对应的金额，帮助观察规模变化。

**交付示例**：“比较这两只成长ETF的共同区间回撤、持仓集中度与费用，并说明差异来自哪里。”

> **使用条件**：收益先对齐币种、分红处理和基准。经理任期外数据排除，共同管理产品的收益不拆成个人能力；完整履历不保证。份额变化金额是估算，并非实际申赎现金流。实时IOPV（盘中参考净值）和PCF（申购赎回清单）不在承诺范围内。

[产品研究入口](compare-evaluate.md) · [基金详细说明](fund-user-guide.md)

## 3. 持仓与组合研究

**能做什么**

- 将同日资产类别、总资产、负债与净资产连接起来，区分总资产占比与净资产暴露；原文空白保留未知。
- 从可解析报告提取股票明细，核对金额、权重与权益合计，展示重叠、集中度和未知仓位。
- 对联接基金及FOF（主要投资其他基金的基金），按报告关系与已知权重逐层查看底层资产。
- 对已核子基金报表，单层分列债券、存款、回购等毛资产和负债；同池份额合并父权重，超过100%的毛敞口不截断，未分类余额保留。
- 复算子基金原文披露的利率情景与单项父持仓静态影响，保留冲击定义和幅度，不把不同情景直接相加或排名。
- 对照多期行业持仓；资料充分时做Brinson归因，即区分行业配置、个股选择及交互作用的贡献。
- 计算基金、ETF、股票及具备合格输入的债券组合的历史收益、相关性、回撤和贡献。
- 比较用户指定权重调整前后的指标。按需运行最小方差、有效前沿和历史分块模拟，观察不同约束与情景的结果。

**交付示例**：“诊断我的基金与ETF组合，哪些行业重复暴露？按我给定的新权重比较风险变化。”

> **使用条件**：穿透需要底层报告与权重，缺失部分保留未知；仅找到目标报告不等于完成加权穿透。股票解析、单层毛资产复算、原文利率情景和完整风险评价分别说明，不能把覆盖率相加。MOM（多位经理分别管理的组合）未公开的内部持仓无法生成。归因须有期初权重、行业收益、匹配基准及一致分类版本。公开快照不能还原真实交易；一次冲击损益不是未来最大回撤。

## 4. 公司与行业研究

**能做什么**

- 获取支持入口中的资产负债表、利润表与现金流量表，整理单季度、同比和环比变化。
- 为指定公司池列财报覆盖清单，获取原文、定位页码、核对支持字段，并生成公司及行业点评。
- 对选定存货分类核对期初期末金额、减值准备与净额，检查加总及逐行关系；可定位到页码与选定单元格。
- 在两期可对应的产品或业务来源组中，拆分收入结构与组内毛利率变化；原金额、比较列和期间分别核对。
- 对普通企业单季同比利润变化作会计拆解，分列毛利、四项费用和未拆分差额；金融企业不套用，缺值不补零。
- 围绕业务、增长、现金兑现和竞争优势组织解释，同时列出反证与待核查问题。
- 在明确假设下计算FCFF-DCF（企业自由现金流折现估值）、同行倍数和简化三表联动情景。
- 采用申万2021版的31个一级行业框架，并进一步按细分业务判断需要哪些经营证据。
- 补充指定美股申报事实，以及债券现金流、到期收益率、久期与凸性测算。修正久期近似衡量价格对收益率的一阶敏感度，凸性描述这种关系的弯曲程度。

**交付示例**：“检查这家公司利润增长是否有现金支持，并与我指定的同行比较。”

> **使用条件**：单位、合并范围与追溯调整需要核对。接口返回完整字段不等于原文逐行核验，31个行业框架也不等于全行业数据齐备。美股申报入口限明确企业编号与指定财务标签。估值依赖输入，不自动补融资或输出目标价；债券基础测算不覆盖完整含权定价，纯债值不保证兑付。异常信号不直接判定造假或必然违约。

[公司与行业入口](company-financial.md) · [行业框架](sw-level1-research.md)

## 5. 宏观与跨资产观察

**能做什么**

- 维护37项指标定义，按用户请求获取已接入的官方观测，列出所属期、发布日期与抓取时间。
- 按原文图例区分同比百分比、绝对变化和百分点，保留单位与原始符号；不将图表读取等同自动核验。
- 按库存、设备投资、建设活动和长期结构变化四条线索组织研究；对应基钦、朱格拉、库兹涅茨与康德拉季耶夫“四周期”。
- 核对同站点归档网页的日期标注，排除晚于研究时点的解读；较早标注不证明历史实际可获得。
- 对照指定宏观序列与科技股ETF QQQ、长债ETF TLT、比特币BTC的共同历史价格窗口。

**交付示例**：“核对这组宏观指标的所属期与发布日期，观察科技股和长债在指定区间的表现。”

> **使用条件**：37项是目录定义数，不是当前都有可用观测。四周期是组织研究的框架，阶段判断须有历史与拐点依据，不能按固定年限推算。同期价格变化不直接证明因果；宏观标签不自动转成ETF配置权重。

## 6. 北交所新股研究

**能做什么**

- 核对发行公告、招股书、文件版本和字段冲突，保留原文依据。
- 在给定配售率情景下，测算整手获配及边际资金档位，也就是资金跨过不同档位时参考获配量怎样变化。
- 按指定新股与日期列现金时间账，检查多只新股、申购和回购的资金占用冲突。
- 保存首次研究及事后实际结果，复盘偏差。

**交付示例**：“按我给定的配售率情景测算百股资金，并检查两只新股的资金占用冲突。”

> **使用条件**：配售率情景、参考百股资金与事后实际获配分别展示，不保证获配或收益。复盘样本不足时不宣称预测改善。完整日历、工作台和部分历史回放需要对应项目资源；工具不执行申购。

## 所有场景共用的能力

| 能力 | 你会得到 |
|---|---|
| 公告、合同与研报阅读 | 条款解释、事件时间轴、核心逻辑、关键假设与跨报告分歧；支持的管理人公开目录可按需检索指定报告 |
| 原文与事实核验 | 证券主体、期间、页码、字段候选、差异及冲突清单 |
| 证据与研究档案 | 来源、输入、公式、参数版本、首次依据、反证和自定义笔记；内容复查绑定具体正文版本及章节原句 |
| 自然语言报告 | 先回答问题，再说明依据、局限和下一项值得核查的证据 |

通常可交付HTML或Markdown。CSV底稿可用Excel打开；带公式的Excel、Word和PPT按组件与授权提供，PPT还需要字体与逐页排版检查。具体参数见[资料与报告索引](capability-reference-index.md)。

## 资料与结论的可信范围

每次研究说明数据时点、来源和计算口径，明确哪些问题已回答、哪些仍不能判断。已取得资料、已复算结果与已核原文分别列明，缺项说明对结论的影响。

代表性案例和剩余缺口见[当前案例范围](acceptance-current.md)。案例只支持其实际核对的期间、字段和环境，不能推广为全市场覆盖、长期接口可用率或统一准确率。

## 共同使用边界

数据按用户请求获取，不保证全量、实时或固定更新频率，也不默认后台轮询。字段缺失与报告缺期明确列示，不填零、不补造。扫描件需人工复核，原文匹配不证明财务真实性。

历史表现、研究假设与实际结果分别展示。工具提供研究资料和计算依据，不提供交易指令、收益保证或确定性价格预测。
