# 验证范围与样本

文档版本：1.0 · 整理日期：2026-10-05

本页给出目前可核对的验证范围，供阅读[功能说明](current-capabilities.md)时判断可用程度。历史样本没有在本次文档修订中重新联网获取；下列记录不构成当前接口可用性或全市场准确率承诺。

## 可用范围怎样界定

| 研究范围 | 当前入口能处理什么 | 每次仍需确认什么 |
|---|---|---|
| 基金与ETF | 按指定代码取得可用净值、行情或资料，解析可处理的持仓报告，使用明确输入比较与测算 | 代码与份额身份、区间完整性、分红资料、报告版式和底层持仓覆盖 |
| 沪深公司财务 | 通用采集含财务摘要；专门的三表入口获取供应商返回的三张报表字段 | 返回的期间及科目范围、单位、合并口径；原文核验另列完成状态 |
| 港美股 | 已接入入口的报价或历史价格；指定美股企业编号与财务标签的申报事实 | 数据源是否返回所需区间、币种、财务标签与主体匹配；不等同全市场完整三表 |
| 行业研究 | 申万2021版31个一级行业的方法框架，指定公司池的财务与原文研究 | 实际公司池、细分业务、原始经营证据和可比口径；框架数量不是实测公司数量 |
| 宏观 | 37项指标定义及已接入的官方观测入口 | 所需指标是否有观测、所属期与发布日期、修订状态；定义数量不是可用序列数量 |
| 北交所 | 已取得发行事实、显式配售率情景、资金档位与现金占用计算 | 公告版本、申购参数和日历资源；情景测算不等于实际获配结果 |

具体来源与采集范围见[数据源登记](source-registry.md)、[独立采集](standalone-collection.md)和[专用脚本调用](integrated-topics.md)。数据源能够访问、字段非空、原文核验通过是不同状态。

## 质量如何呈现

一次研究分别交代资料是否取得、计算是否完成、哪些字段已核验。缺项说明影响，例如“缺少目标ETF持仓报告，因此不能确认这一部分底层行业暴露”。成功部分保留，失败部分列明原因和可补充的资料。

目前没有代表性抽样下的全市场核验通过率、长期数据源可用率或完整跨平台导出验收。也不把测试用例数、题库规模、优化轮数或主观评分换算成这些指标。未来新增验证时，应同时记录样本范围、成功与失败数量、期间、环境和原始证据位置。
