# 行业经营逻辑与证据检验

用于公司深度研究、公司一页纸、行业财报点评，以及解释基金或ETF底层行业暴露。先识别实际收入和利润来源，按业务选择下表；多业务公司可同时采用多行。行业名称不明确时先查看业务分部，不猜分类。此参考增强研究推理与交付，不新增数据接口、自动预测或评分模型。

按申万一级行业选择时，先读[SW2021全部31行业索引](sw-level1-research.md)，再使用本参考的细分业务方法。这里的业务类别与申万一级行业不是一一对应，航空、机场等属于交通运输的细分经营方式，不能作为新的一级行业。

## 四个研究问题

需要进一步评价壁垒、验证原因或比较估值假设时，读取[研究判断与检验方法](research-methods.md)，与以下行业变量共同使用。经营框架说明查什么，方法框架说明怎样检验和更新判断。

1. **经营变化来自哪里？** 区分数量、价格、产品结构、成本、费用、合并范围和一次性项目。财报同比只是结果；公司解释是来源陈述，尚不是原因已证实。缺少分部或运营数据时，仅列候选解释和待取证项。
2. **利润是否兑现为现金？** 对照利润、经营现金流、应收、合同资产、存货、预付款和资本开支；把建设、备货、账期、季节性等替代解释并列。金融企业使用专属资本、资产质量与负债框架，不套普通企业现金利润比。
3. **什么会推翻判断？** 为关键假设列支持证据、反证条件和未知项；阈值由用户或有据模型提供，未给阈值时用可观察方向，不编造数值。缺少反证不等于假设成立。
4. **下一步跟踪什么？** 指定指标、来源、所属期、披露日和可比口径；用户下次主动请求时核对。未取得数据不承诺自动监控。

## 按经营方式选择框架

| 业务 | 驱动拆解与优先证据 | 现金及反证检查 |
|---|---|---|
| 钢铁 | 分产品销量、售价、原料及能源成本、产能利用率；需求分建筑、汽车、制造等 | 库存涨价收益与持续价差分开；新增产能、需求下降或价差收窄可能推翻盈利改善判断 |
| 化工 | 产品与原料对应、单位耗用、产能投放、检修、开工率、库存与竞争结构 | 产品涨价不等于利润改善；核查原料同步涨价、库存成本、环保投入和新增供给 |
| 机械 | 下游客户资本开支、订单、新增与替换需求、交付、产品结构、服务收入 | 订单取消、交付延迟、应收和存货积压；新增订单不直接等于当期收入 |
| 汽车 | 销量×单价及车型结构、渠道库存、产能利用率、单车成本、研发和促销 | 批发与终端销量分开，警惕压库；新能源和燃油车业务分开，不沿用历史估值折扣 |
| 家电 | 新增、替换需求与渗透率，价格、产品结构、渠道、原材料和汇率 | 渠道库存、应收、促销费用及售后；收入增长是否伴随终端销售与回款 |
| 零售 | 同店增长、新店贡献、客流、客单价、营业面积、租金及费用 | 总额与净额收入区分；扩店可能增加收入但降低现金回报，关注闭店和库存周转 |
| 纺织服装 | 加工制造看订单、产能、原料、汇率；品牌看同店、折扣、门店、库存 | 订货与实际销售分开；明确库存销售比的分子、分母和期间，避免沿用含混名称 |
| 建筑 | 新签订单、在手订单、转化进度、合同毛利、项目类型和收入确认 | 合同资产、应收、预收与回款；合同总额不直接等于可确认收入或可收现金 |
| 房地产 | 项目销售、价格、竣工交付、结转、存货减值、土地及项目结构 | 销售回款、受限资金、债务到期和融资；项目价值、企业价值、股权价值分开，NAV不保证变现 |
| 航空 | ASK、RPK、客座率、单位客运收入，航线结构、油价、汇率、租赁 | 运力增长不等于盈利增长；单位收入与成本用相同分母，剔除汇兑等非运营因素后再解释 |
| 机场 | 起降架次、旅客吞吐量、收费和非航空收入、商业合同、投产与折旧 | 扩建资本开支与新增收入兑现时间；商业租赁条款、最低保障与分成需原文支持 |
| 航运 | 贸易吨海里、船队交付与拆解、航速、拥堵、航线、运价和租约 | 现货与长约区分；TCE等指标须核对定义，船舶重估需扣净债务及合同承诺，不设价格底线 |
| 公路 | 路段流量、车型结构、收费、竞争路网、维修和特许经营期限 | 有限收费期现金流，期末处置义务和资本开支；不默认永久经营或机械套永续终值 |
| 铁路 | 货运量、周转量、运距、货种、运价、网络与运能 | 运量与周转量区分，关注资本开支、运能瓶颈、客户集中及结算 |
| 电力 | 分火电、水电及新能源；电量、电价、利用小时、煤价或来水、装机和交易结构 | 市场化与非市场化收入分开；来水、燃料、限电、补贴应收、资本开支与融资分别检查 |
| 电力设备 | 客户投资计划、实际招标、订单、中标份额、交付和技术路线 | 规划投资不等于公司收入；核查交付周期、毛利、回款与新增竞争，不沿用旧装机预测 |
| 电子 | 终端需求、渠道库存、产能、利用率、良率、售价与技术迭代 | 库存调整与终端需求下降分开；行业复苏不自动证明某公司受益，需客户及产品证据 |
| 计算机 | 按软件、服务、硬件等分部，订单、履约、收入确认、人员与研发费用 | 签约、收入、回款分开；研发资本化、应收、续费及客户留存按可得资料检查 |
| 医药 | 原料药、制剂、创新药、流通、服务分开；量价、研发阶段、竞争与准入 | 临床成功、审批、商业化分开；专利及采购规则需当期原文，研发支出不直接等于技术价值 |
| 传媒 | 按内容、广告、游戏、出版等业务；用户、付费、投放、版权、项目周期 | 流量不等于利润；项目确认、版权减值、获客费用、回款及收入集中分别检查 |
| 银行 | 生息资产规模、净息差、非息收入、费用、信用成本、税率 | 资本约束、资产质量、拨备、存款成本与期限错配；PB必须结合ROE和资产质量，不设最低估值 |
| 保险 | 寿险看新业务、有效保单、费用与投资假设；财险另看承保与赔付 | 资产负债匹配、退保、准备金和资本；EV/NBV仅在披露定义一致时比较，不套旧会计和监管参数 |

## 从财报到解释

- 先核对报告期、披露日、合并范围、币种、单位、会计和行业分类版本；累计经营陈述不直接解释单季差分。跨期重述按现有跨期核验流程处理。
- 数量×价格模型只在单位、期间、产品范围匹配时成立。只有总收入变化时，不把未知销量或价格反推成事实。若有匹配量价，可用显式约定的分解顺序或对称分解，保留交互项和产品结构影响；未执行计算不写数值贡献。
- 现金差异先列报表事实，再列公司解释与替代解释；没有回款、账龄等证据时不作财务造假、收入虚增或确定违约判断。
- 行业比较隔离经营模式和口径：零售总额/净额、航空航线结构、船运租约、银行/非金融等不能只按行业标签直接排名。指定样本不冒称全行业。
- 估值选择依赖现金流稳定性、资产性质和业务阶段；历史PE/PB区间、周期时钟、固定宏观滞后期不作为默认参数。亏损时不能把负PE解释成便宜；债底不保证兑付。
- 宏观与策略使用“观测→传导假设→行业变量→公司暴露→反证”的链条。同一政策可能有相反影响；政策目标、公告落地和实际经营结果分别列示。量化关系另做样本外检验，历史相关不等于因果。

## 交付方式

正文先用自然语言说最重要的经营变化及其意义，随后给依据、替代解释、现金检查和未决问题。不要把提取成功、核验条数或本参考的步骤当作重要发现。

需要细节时附表：`研究判断 | 支持证据及页码 | 反证或替代解释 | 缺口对判断的影响 | 下次核查指标`。没有支持证据的判断写成待验证假设；证据有限时不输出数字评分。与已有公司简报章节businessSegments、financial、forecast、risks、tracking衔接；保持原有来源、日期、定位和basis字段，不把方法提示伪装成已取得数据。

基金/ETF场景只解释已披露行业或底层公司的驱动。先标明持仓日期及覆盖比例，不用行业特征替代基金真实仓位，不据此预测净值或输出调仓指令。

## 行为验收案例

| 输入情形 | 应交付的研究判断 | 应阻止的错误 |
|---|---|---|
| 化工收入增长，但只有总额及原料涨价新闻 | 收入增长已知，量价和利润改善原因待取证，核查产品价格及成本 | 自动认定产品涨价贡献或利润改善 |
| 建筑新签大合同，尚无交付回款 | 订单提高业务储备，收入和现金兑现依赖履约，列进度及付款条款缺口 | 合同金额计入当期收入 |
| 银行经营现金流为负 | 检查资产负债扩张、资本、信用及资金来源，保留专属资料缺口 | 套普通企业现金利润比认定低质量 |
| 航空客座率提高，但票价、航线和油价缺失 | 效率改善，不足以确认盈利改善，列单位收入与成本核查 | 推导净利润增长率 |
| 公路收费权剩余八年 | 估值情景限八年及有据处置事项，参数缺失留空 | 自动添加永续增长终值 |
| ETF仅取得前十大持仓 | 限已知持仓讨论行业暴露和驱动，未知部分列示 | 宣称全组合行业归因已完成 |

## 方法来源与维护

本框架参考用户提供的中信证券24份行业与宏观、策略、债券、量化研究方法材料，重新组织为研究问题与证据检验；未附带或复制原PDF、图表和历史推荐。原始材料主要使用较早时期案例，现行规则、统计定义与市场结构须按实际研究截止日核查。文件名页数与实际页数可能不同；方法参考不等于原文已完整图表验收，也不代表取得第三方材料再分发许可。

跨发布统计比较时，将当期官方同比说明、上期原公布值及复算差额分别留存。直接相减不一致时，不静默替换历史值，不在缺说明时认定修订或舍入。判断先说明差异是否影响方向或量级；小差异作口径附注，不夸大为投资催化。

统计符号口径可用 `python scripts/statistical_change_units.py INPUT.json --out NEW.json`，复用已核读表头、脚注及单元格。输入提供来源文件和SHA256、脚注位置、符号到percent/absolute/percentage-point的映射、无符号列口径及所选指标原单位和变化文本。工具检查来源哈希并按声明脚注解释，绝对量沿用指标单位，百分点不写成百分比；未知标记拒绝，缺值留空。它不读图做OCR、不认证输入语义或自动推算历史基数。
