# 公告专题底稿复查

运行`research-workbench script disclosure_review review --input 完整底稿.json --out-dir 新目录`。支持业绩预告、股东户数、股权质押、限售解禁、定向增发、问询函/关注函、同业竞争、股权激励八类输入复核。各记录须明确主体、公开/取得时点、来源版本、原始摘要及定位；示例在examples/disclosure-teaching.json，为原创合成，不能冒充真实公告。

业绩预告核期间、归属、口径、单位和上下限，零/负基数单列；不把预告当实际。股东户数按份额类别和范围比较，变化不识别账户。其他专题只保留事件日、陈述、分母和实施依据，结构通过不认证经济/法律事实。更正前后并列；未知不补零，截止后资料排除。

本入口不是任意PDF抽取器、全量公告采集器或规则适用判断器。已有公告目录负责候选获取；专题底稿需人工原文核对。规则库负责规则/版本，数据仓负责响应，工作台负责组织与解释。
