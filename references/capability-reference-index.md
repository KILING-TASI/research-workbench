| 场景 | 阅读内容 |
|---|---|
| 专业方法、法规、合同或统计口径 | [各类研究适用依据](research-basis-standard.md)；财务研究补读[会计与审计依据](accounting-audit-basis.md) |

| 买方逻辑与投后跟踪 | [投资假设档案](buy-side-thesis.md)，保留首次依据、反证和未验证事项 |
| 深度报告与交付检查 | [研究流程](research-operating-flow.md)、[深度交付标准](research-depth-standard.md)、[报告内容验收](report-content-acceptance.md) |
| 查询工程实现或维护代码 | [共用能力分工](shared-research-layers.md)、[基金代码索引](fund-code-map.md)；普通查询不默认读取 |

依据须核对市场、有效版本及适用对象；框架、假设与数值核对不替代真实取数、因果识别或合规判定。
