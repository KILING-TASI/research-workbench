# 杜邦与资本回报分解

ROE拆成净利率×资产周转×权益乘数，只在相同期间和一致的平均资产、平均权益口径下使用。归属母公司利润不能机械除合并全部权益来凑分解；负权益和一次性利润须另述。ROE提高先查权益收缩与杠杆，不直接归为竞争优势。

ROIC使用声明的税后经营利润与投资资本。投资资本可按经营资产净额或融资口径构建，但须逐项对齐并交叉解释差异；总资产不是自动替代，净利润也不是税后经营利润。平均与期末口径、租赁、商誉和非经营资产调整保留依据。

稳定经营回报假设下，增长可用再投资率×资本回报检查一致性；效率变化、并购、亏损及金融企业不能机械套用。10%资本回报与50%再投资支持的5%是条件式算术，不是预测承诺。

本页组织现有财务核对与研究解释，不新增自动会计调整器。主题依据：[增长与再投资](https://people.stern.nyu.edu/adamodar/New_Home_Page/littlebook/growthvaluedrivers.htm)。
