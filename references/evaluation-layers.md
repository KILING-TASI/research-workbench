# ETF 三层评价

按以下顺序独立输出，不以单一总分替代证据。

1. 指数评价：编制规则与调整、成分及行业集中度、估值与盈利质量、历史风险、市场及汇率暴露。先确认指数版本、币种与目标敞口。
2. 产品评价：同指数共同日期比较费用、净跟踪差与误差、规模与份额稳定性、成交与价差、折溢价、复制与申赎、运营风险。费用已体现在净值收益中时不得重复加分。
3. 组合适配：真实持仓重叠、风险贡献、期限、资金约束、成本回本与再平衡。没有完整持仓和共同历史，不输出风险贡献或适配结论。

每项列事实、来源、时间、比较口径、风险和缺项。第三方观测、官方核对与评价通过分别表达。缺项不填零，不输出未经验证的综合优选排名。当前工作台将已有替换研究逐层展示；待补项不是已完成的数据接入或模型。

## 可执行计算

替换研究入口同时生成 evaluationLayers，工作台导入同一结果。新增集中度（前十权重、HHI、行业权重）、全收益指数波动及回撤、全收益净值跟踪差及误差、历史订单占比、成分重叠。缺依据返回 null，不作总排名。

输入 current/candidate 可附 constituents、indexTotalReturn、navTotalReturn 证据对象；共同字段为 value、sourceUrl、locator、observedAt、availableAt、verification。constituents.value 为 code/weight/sector 列表，weight 为0—1小数，必须完整且总和为1。序列 value 为 date/value 列表；basis 分别 index-total-return 与 nav-total-return；附 currency、indexId、indexVariant。币种、指数版本、日期完整一致，至少121期；252期年化，跟踪误差为日收益差样本标准差×√252，净跟踪差为两序列年化收益之差。当前修订历史不能冒充历史时点可得序列。

portfolio 可提供 code/constituents；成分重叠=sum(min(两边同证券权重))，要求完整同日成分；不等于组合风险贡献。报价日期、历史区间必须保留，旧数据不是实时数据。规模、估值、盈利、运营与组合风险贡献仍需补数据。示例证据的人工核验登记由用户或研究者承担，程序不独立证明真实性。

## 官方指数与财务接入

独立使用 `python scripts/collect_index_evidence.py --data-dir 用户目录 --index 000300 --start 2024-10-08 --end 2026-09-30`。保存每次独立快照、原文链接与哈希，失败不覆盖旧成功数据。同类别多份文件分别保存；collection.json.errors逐项记录异常，部分下载成功不代表全目录已取得。接口对000300只选择唯一合法的CSI 300 TRI候选；该名称线索不能替代人民币币种与全收益方法核验，既有映射案例也不能自动认证新响应。其他指数不猜H前缀。官网资料接口按fileLang=2查询编制方案、权重与估值文件，是否完整及所属期均须读文件确认。XLS使用环境可用的文件阅读工具；组件不可用时保留原件并标记未解析，不承诺任何环境都能读取。

完整成分入研究输入后，独立执行 `python scripts/collect_constituent_financials.py 输入.json --period 2026-06-30 --out 新财务.json`。抓取主候选两方成分的财务并过滤NOTICE_DATE；NOTICE_DATE为第三方披露日，不等于逐公司官方公告核验。missingCodes列出未返回合格记录的代码，excludedRecords说明响应中因币种或日期被排除的记录；未出现的代码不能直接断言未披露。coverageStatus=partial时不得称全成份财务取得完成；同公司多个修订版本需先核对，非法分页或数值明确报错。归母利润单位元，经营现金流每股单位元/股，后者仅取符号，不能当总额。financials.value字段code、period、publishedAt、netProfit、operatingCash或operatingCashPerShare；financials.unit=CNY。同财报期、完整权重下输出覆盖比例与事实；不足80%不判断质量。金融企业现金流不可直接与实业比较。

真实portfolio为code/weight/navTotalReturn/constituents列表，权重为0—1、总和1、代码唯一。至少121期完整共同交易日、同币种全收益，算252期年化协方差及方差贡献。贡献可为负，不等于收益贡献。基金实际成分缺失时不以指数成分替代持仓重叠。真实持仓未提供留空。

本轮两只产品案例：485个共同净值与官方全收益日期，300项官方指数成分，300家同报告期第三方财务，8笔现金分红已逐笔核对上交所金额和除息日。净值未逐日官方核验；按除息日净值理论再投资，不模拟现金红利发放等待。份额仅6个非等间隔统计日、净资产5期；不以此宣称连续稳定性或净流入。实时PCF、最新招募版本及逐项财务原文核验仍需补，不能声称全市场完整择优。


来源状态：第三方规模、折溢价及估值观测不标为官方原文已核验。未核验分红事件的净值风险标为研究测算。历史序列明确标为weekly/monthly时，不按日度252期年化；旧输入未声明频率沿用日度假设，并提示交易日历未独立核验。


定期报告中的“净值增长率－业绩比较基准收益率”只称合同表同期收益差，不直接称选股alpha、跟踪误差或复制能力改善。先确认基金分红处理、指数价格/全收益版本与共同日期。场内未复权价格不能代替总收益净值；股票持仓权重以净资产为分母时，前十合计必须明确分母，不与归一化股票仓位混比。
