# 基金研究功能说明

直接输入代码或问题即可使用，工作台不是必需。分析结果附数据日期、口径、资料来源和缺项，不构成投资建议，历史表现不代表未来。

以下按五条基金研究流程组织，与总功能说明共用取数、证据和报告能力。

基金评价先回答产品定位、业绩质量、风险代价、投资过程、经理团队、公司治理、成本与组合用途，详见[评价框架](fund-evaluation.md)。指标和原文核验支撑判断；Brinson是按需收益来源专项，不是每份评价的必备前提。

## 术语与口径

年化收益率采用时间加权收益序列的几何年化（CAGR），不是算术平均年化，也不是投资者现金流加权收益率。行业分布变化不等于价值/成长风格漂移。

## 1. 产品评价、比较与投入成本

- 计算历史收益、年化收益率（时间加权）、最大回撤、波动率、夏普、索提诺、卡玛与历史相关性。
- 多基金先对齐共同观测日期，再输出分项对比；支持近1、3、5年等指定窗口。
- 收益率按净值序列计算，资料准备时明确分红处理方式，默认红利再投。分红/拆分工具在事件记录完整且已核验时，可计算红利再投与保留无息现金两种收益口径。当前比较引擎接收已处理的总收益序列；现金分红结果为基金市值加现金的账户收益，不能称为基金净值。
- 基准可由用户指定并提供来源，也可从已核验合同确定；实际计算仍需取得基准序列，不承诺内置全量对照表。报告列明基准名称、来源、区间及是否与合同一致；未核验合同基准时标注未核验，自定义基准不冒称合同基准。
- 输入池中位数不等于全市场同类中位数。
- 指标附定义与局限；数据缺失不填零，不把不同风格直接作为同类排名。

示例：比较110022和161005近3年收益风险，并说明投资范围差异。

先核对最新费率公告及适用日期；现行费率不能直接当作历史费率。

- 比较一次投入及分批定投的申购、赎回和持续收费。
- 按输入费率、费率阶梯及持有时间计算费用差额与临界点。
- 净值已包含的运作费不在历史收益中重复扣除。
- 费用较低只是当前假设下的成本结论，不是产品买入建议。

### 费用测算假设

明确每笔申购金额及日期、定投频率与期数、持有期限、申购折扣、赎回阶梯和持续费率。费用临界点模型假设费前净值恒定，持续费用以连续年率近似计提，不含税费、固定/分档申购收费、产品赎回限制和实际投资收益。货币基金不默认套用普通净值模型；债券基金也需核对份额结构及收费规则，不能只按名称套算。

历史定投另使用已取得的净值及分红、拆分事件，支持固定金额或份额、周/月计划、多方案和逐期明细，见[定投规范](fund-dca.md)。费用临界点假设不套用于历史定投收益；累计收益率和现金流年化收益率分别说明。

## 2. 持仓结构、经理观点与归因

- 从可解析版式的年报、中报提取完整股票表，核对连续序号、逐行金额/权重与权益合计。扫描件或特殊版式需人工辅助提取及复核。
- 核对结论列明提取合计、报告披露合计、金额差异与一致性状态。现有完整股票解析器遇到合计不一致会停止生成完整持仓结果，须保留差异说明，不能把失败结果称为完整通过。
- 比较净资产口径重叠、已披露股票内部归一化重叠、共同持股及双方独有持仓。
- 展示行业分布、集中度、前十大及未知仓位；行业分类需有依据。
- 在指定基金池内检索持仓相近产品，不声称覆盖全市场。
- 多期报告可观察证券出现时间线、仓位变化和榜单变化，不能还原真实交易或精确持有期。

示例：这两只基金完整持仓重叠多少？前十大不同是否代表分散充分？

- 经理观点仅取已取得年报，区分报告回顾与展望，保留页码。
- 多期行业或风格分类快照比较；完整持仓、分类版本和覆盖均满足时才输出分布变化量。
- 有期初权重、行业总收益及匹配基准时计算Brinson配置、选择与交互贡献。报告注明行业分类体系及版本（如申万一级或中信）；跨期分类须已核验且一致，否则不输出分布变化量，不直接拼接归因。
- 支持多期归因并排和连续期间链接；缺期不补造，未解释真实交易部分单列。
- 公共报告自述不等于能力已验证。

示例：提取2025年年报中的经理观点，比较连续季度行业变化。

## 3. 条件筛选、基金池与批量诊断

- 历史指标筛选器支持：最大回撤、年化波动率、夏普、索提诺、卡玛、年化收益率。专项事实条件可检查有来源的规模、费用等数值；成立年限、机构持有比例需先取得及组织相应字段，不承诺自动全市场采集。
- 支持大于、小于、等于及含等号的数值阈值，多条件同时满足；区间拆为上下限。相对分位或池内中位数条件须先计算并注明样本，再转换为数值阈值，不是原生相对阈值语法。
- 输出通过清单、未通过原因与缺失指标；池内评分另生成排序表，可加入对比并导出。缺值不视为通过。
- 保存观察池、用户自定义指标及权重，主动触发池内评分和精简诊断。
- 筛选结果可加入指定池或对比；评分要求可比窗口与分组。
- 在已有报告范围内按股票或行业反查持有基金。
- 批量轻量扫描只处理已有历史数据，不自动替代全文深度研究。

示例：按回撤40%、夏普60%给我的观察池评分，列明缺项。

## 4. 组合、FOF与情景研究

- 基金、ETF、股票、债券可合并研究，计算共同区间收益、相关性和组合历史风险。
- 拆解资产收益贡献、波动风险贡献及同一组合最大回撤区间的损失贡献。
- 比较用户指定权重调整前后的历史指标、集中度和压力情景。仅为历史回测与情景模拟，不构成交易指令，亦不代表未来最优配置。
- 按需运行最小方差、有效前沿及分块模拟；模型输出不代表未来最优配置。
- FOF逐层穿透已取得的子基金报告；报告缺失保留未知资产与路径，不能穿透未公开MOM持仓。
- 一次冲击损益不等于未来最大回撤，相关性与流动性可能变化。压力参数由用户指定，或作为明确标注的研究假设；模型不预测未来波动率。

## 5. 文档核验、研究档案与报告

可回答：“这只基金能否投资港股通？”“封闭期多久？”“巨额赎回如何处理？”“是否有侧袋或业绩报酬条款？”回答给出条款结论、适用条件、原文页码及来源，资料不够时明确无法确认。

- 阅读已取得合同、招募说明书、年报与公告，定位投资范围、港股限制、封闭期、流动性、巨额赎回、侧袋及业绩报酬条款。
- 核对报告身份、报告期、引用页码和文件哈希，发现同名字段冲突时保留歧义。
- 条款标签和关键词只是定位线索，结论须阅读上下文；扫描件/图片型PDF提取效果有限，需人工复核；无可读文本时不能声称已完成原文核验。
- 检索某入口失败后继续其他正式披露入口与原文线索，不能把未完成检索称为资料不存在。

合同与招募说明书出现同字段冲突时，标注冲突项，并核对文件有效日期及已生效修订。涉及合同权利义务，以有效基金合同及合法生效的修订为核对依据；不能仅凭文件名称自动裁决所有数值冲突。当前需阅读原文判断，不宣称已内置自动法律优先级裁决。

本模块基于已有研究结果汇总，不会凭模板补齐缺失资料。

- 汇总历史表现、持仓、经理观点、已有归因、组合贡献及证据缺口。
- 支持导出格式：HTML、Markdown；Excel在运行环境具备导出组件时提供，交付前检查是否可用。
- 支持单基金、基金池、FOF、跨资产专题模板。
- 保存历次研究快照、标签和自定义笔记，保留来源与参数；本地资料需自行备份。

## 数据质量、收益口径与研究版本

- 净值质量：核查异常跳变、连续不变、已知日历内缺失观察；没有已确认适用的交易日历时不输出完整度百分比。核查线索不直接认定数据错误或停牌。
- 分红与拆分：完整事件记录可支持红利再投、保留现金两种收益及拆分处理，保留输入和因子版本；事件不完整时不计算。
- 多基准：可构建用户指定权重的研究参照，明示每观察期再平衡或买入持有，计算超额、跟踪误差、信息比率、Beta与Jensen Alpha；注明合同基准是否核验一致。
- 快照对比：比较同一研究对象的指标、来源与报告版本；口径改变时只并列提示，不输出伪可比差值。原始快照不覆盖。

这些结果可进入研究档案及综合HTML/Markdown报告，按已取得结果展示；结论可展开查看原文页码、计算参数及逐项局限。

## 可复查的证据与结论

研究解释增强：可把已披露底层行业暴露与[行业经营驱动](industry-operating-logic.md)联系起来，解释为什么不同产品可能承担相近风险；按[研究判断方法](research-methods.md)区分事实、经理自述、研究解释与待验证假设，识别同源材料、反证和口径变化。仅基于取得的持仓和数据，不扩大为全组合归因，也不将产品表现直接归为经理能力。

原文披露、确定性计算、假设估算、缺失与冲突分别标记。结论绑定证据、来源页码和必要局限；有原文PDF时可保存行区域与文件版本，点击回到原文页。计算记录公式、输入证据和参数，但不冒称全部公式已经自动复算。

完整报告日持仓不等于逐日精确归因。数据覆盖率说明已知部分占比，不是准确率或置信度。缺失、冲突与假设不能经计算包装成确定结论。没有统计依据不生成置信区间。

证据包和笔记保留新旧版本，可比较来源、解析、口径和结论变化；笔记可绑定具体证据或结论。版本变化不自动认定为经济事实变化。


基金评价基础补充：产品定位、规模与持有人结构、已核验任职区间分析及缺口清单。调用 `python scripts/fund_evaluation.py INPUT.json --out NEW.json`，输入与边界见 [fund-evaluation.md](fund-evaluation.md)。报告以自然语言解释结果，不将产品表现直接视为经理能力。


历史定投回测：支持固定金额/份额、每周/每月计划、现金分红/理论再投、总投入、期末资产、累计收益率、XIRR、逐期明细及同基金多方案对比。事件完整性和申购费假设必须说明，期末资产不等于赎回到手收益。调用与参数见 [fund-dca.md](fund-dca.md)。


经理任职与产品关系：支持按姓名汇总已取得报告中的产品任职记录、区间表现、共同管理和冲突项，最新在管状态需最新证据。参数见 [经理任职](manager-products.md)。

## 资料与运行边界

| 项目 | 提供/处理方式 | 不承诺 |
|---|---|---|
| 数据时效 | 显示观察日期、获取日期及来源 | 实时行情、固定更新频率 |
| 报告取得 | 按需检索公开披露渠道，记录具体缺口 | 任意基金全量资料自动闭环 |
| 缺失处理 | 字段缺失、报告缺期留空或明确标注 | 插值、回填、补造或将缺失视为零 |
| 经理观点 | 已取得年报回顾与展望 | 路演/采访抓取、经理完整履历 |
| PDF解析 | 可解析定期报告；特殊版式人工辅助复核 | 扫描件完整自动提取、全文提取等于表格勾稽 |
| 基金筛选 | 指定输入池、已取得字段及明确规则 | 全市场同类排名或筛选结果的未来有效性 |
| 监控 | 用户主动触发资料检查 | 后台全天轮询与自动告警 |
| 测算 | 历史统计与列明假设的情景 | 未来收益/波动率预测、损失上限、未来最优方案 |
| 研究用途 | 客观信息、来源及局限 | 投资建议、交易指令或可直接据此决策的投资依据 |

报告获取、数据计算与原文核验分别说明完成状态。公开持仓不能还原真实交易；所有输出均需结合资料时点与口径理解。


### 选定净值交叉核对

`python scripts/nav_crosscheck.py INPUT.json --out RESULT.json` 接受同一基金、同一单位净值口径的两份来源观察。输入指定代码、截止日；各来源保存URL、取得时间、代码、`basis: unit-nav`及含日期和净值的摘录。金额用十进制字符串。按日期交集逐项输出差额，来源独有日期单列，冲突保留，不平均或填零。

交付说明核对了哪些日期、是否一致及对研究判断的影响。选定日期一致不认证来源真实性、分红完整性、交易日完整性或全区间收益；官网与渠道还可能共享底层数据。官网未列分红记录不自动转换成已核验无分红。


### 报告期间收益与净值端点核对
`python scripts/nav_crosscheck.py INPUT.json --mode period-return --out NEW.json`。仅在原文明示该期未分配时使用。输入code、shareClass、periodStart、periodEnd、baselineDate（期初前一日），unitNavFile、pdfFile及各自对应的unitNavFileSha256、pdfFileSha256，reportedReturnPct（十进制字符串），以及periodEvidence、performanceEvidence、noDistributionEvidence（各为page、quote）。净值文件为已取得的单位净值加分红归档格式，包含code、historyBasis: nav-with-distributions及history；报告身份和份额事先核对。

模块重新读取PDF页文，匹配报告期、相同份额的净值增长率和本期未分配声明，使用两个准确日期端点复算并按百分比两位比较。缺基准日、日期重复、数据源分红与未分配声明冲突时拒绝；不近似替换日期、不插值。结果保留原值、显示值、差异百分点、原文定位与输入哈希；冲突保留。原文明示无分配仅覆盖该报告期，不能凭接口空字段认证全历史无分红；有分配的期间须另核对完整事件及再投模型，不套用此入口。核对一致不证明全历史完整或官方来源真实性。

### 基准生效期与历史比较

发现基准修订时，分别记录原公式、新公式、公告日、生效日和原文位置。半年度结果按当期适用基准解释；跨生效日的超额收益研究须取得分段匹配基准，不拿当前官网公式回填整段历史。`fund_research.js compare` 的 `reference` 可提供 `validFrom` 与 `validThrough`（YYYY-MM-DD）；共同窗口超出声明有效期时停止对标。未提供生效信息时明确登记未声明，不认证合同基准有效性。此检查只核输入日期范围，不自动拼接指数或核验公告；其他计算入口须同样前置人工核对版本。

报告期收益核验的命令行入口将 `unitNavFile` 与 `pdfFile` 的相对路径解析为输入JSON所在目录下的文件；绝对路径保持原意。切换工作目录不应改变所选原件，文件哈希仍须匹配。Python函数直接调用时由调用者提供有效路径，或先调用 `resolve_period_paths`。

收益摘录须直接连接所选份额及其净值增长率，不能拿同段其他份额或基准的数字匹配；净值摘录须匹配完整十进制数字，百分比、科学计数法和数字片段不会作为单位净值通过。解析失败保留为待核，不猜测换用其他字段。

年报经理任职表若职务跨页续写，应在连续页读完后分类；明确“任本基金”表头可用于确定行的所属产品，缺少完整职务的行仍列为歧义。`report_manager_tenure.py`命令行将归档记录中相对`documentPath`按归档JSON所在目录解析，文件哈希继续核对。产品类别首次管理时间不替代本基金任职日。
