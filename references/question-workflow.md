# 统一问题研究入口

research_pipeline.py research-question 输入.json；沿用 --workspace 和 --out。

```json
{"question":"分析招商银行最近三个月有什么重要公告变化","asOf":"2026-10-03","refresh":true}
```

宿主聊天负责给定研究截止日。当前为有限规则路由，不是通用语言模型：仅接通单公司A股公告链。支持问题中的六位代码、精确公司名称、近一/三个月；也可指定query或code。缺省1个日历月，refresh缺省true。独立安装没有目录时onlineSearch=true获取第三方身份候选，候选未唯一、目录结果截断、参数冲突或不支持窗口时不执行事件采集。不凭代码前缀确定品种。

流程：问题识别→身份检索→窗口检查→公告采集→分类与研究线索→事实/假设/缺项输出→独立运行档案。计划性事件与已实施事件保留区别。事实仅指目录/公告元数据陈述，不等于正文验证。status=partial表示已取得线索但缺原文、财务/行情对照，不是研究完成。

answer为可读摘要，eventResult保留时间轴，facts标注元数据等级，hypotheses保留影响路径。原文核验、财务勾稽、估值模型、组合计算还未自动串入此入口，不以已有脚本冒充全流程接通。涉及买卖、涨跌的提问仅提供客观事件资料，不生成交易判断。

每次保存research-data/question-runs/唯一ID下的input.json、result.json、answer.md，包括输入哈希、调用模块代码哈希、检索来源、采集时间与错误。未取得原文不虚构页码或引文。档案供复查，不等于历史时点冻结公证；后续修订另生成档案。

其他研究通过主Skill对应专题流程调用；工作台可选。此入口只串联公告线索，不代表全部深度研究流程已自动接通，不创建常驻调度。
