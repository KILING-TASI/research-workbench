# 基金投资会计核对

对已取得、完成身份匹配的年报或中报副本，核对基金投资明细与当期资产负债表基金投资余额、净资产分母。按原文当前列取值，保留页码、表格坐标、原始单元格和文件摘要；重复字段冲突即停止，不用总资产代替净资产。

```powershell
python scripts/fund_investment_reconcile.py REPORT_RESULT.json --out NEW.json
```

输出JSON、Markdown和HTML：每项披露金额与权重、核验的净资产权重、基金投资会计余额、明细合计、差额、核对状态。金额以十进制逐分比较，披露百分比允许其两位小数四舍五入误差；比例不符时不输出已核验权重。

前十名金额合计等于基金投资会计总额，只说明该金额关系核对完成；不证明所有经济风险都被该表覆盖，不包括期货名义敞口、现金或直接股票。子基金代码与底层报告仍需单独关联，不能直接称为全组合穿透。差额不为零时明确显示未覆盖金额，不将其填补或归入现金。
