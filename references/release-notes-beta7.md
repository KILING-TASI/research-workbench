# v0.1.0-beta.7 发布说明

`v0.1.0-beta.7` 已于 2026-10-10 发布。[Release 页](https://github.com/KILING-TASI/research-workbench/releases/tag/v0.1.0-beta.7)提供安装 ZIP 和 SHA256 清单。资产、标签及历史结果保留原样；这次仅更新源码中的发布状态说明。

这版把已合并的修复和首页说明整理到安装包中。依赖检查只针对所用入口，缺专业工具时说明怎样补齐，不阻断其他研究；专业代码加载修复了目录切换和初始化失败的缓存问题；预测档案会先验证本次输入，再合并旧记录，并分别保留声明的报告版本。

首页说明了离线试用、真实 Skill 名称、专业依赖及旧安装包的区别。可转债直接命令行生成报告后会提示结果位置和打开哪个文件；提示写入 stderr，原来供程序读取的 stdout 和结果字段不变。

软件版本为 `0.1.0-beta.7`，说明版本仍为 `1.93`。现有输入接口、规则与计算方法编号保留；软件版本不代表预测、原文认证或视觉能力的新承诺。

最短试用仍是：

```powershell
python scripts/start.py demo --out-dir local-data/first-comparison
```

这是教学数据；输出目录已存在时换一个名字。六列股票表解析、schema1 原页核验和账户收益计算需要对应兼容的专业工具，ZIP 不自动安装它们，也不带第三方运行库。

不增加新投资模型、定时任务或交易功能。安装包不含作者账户、私有缓存、原始 PDF 和全部行情数据；代码 MIT 与第三方、数据权利分别处理。旧 Release 和用户已安装的文件不自动替换。
