# 报告任职到经理产品关系

直接输入已取得的基金档案，核对PDF摘要与报告身份，从基金管理人与托管人章节读取明确管理公司，重新提取经理任职表，保留经理、助理和歧义角色。按公司与姓名形成指定池内候选身份，不冒称全市场或完整职业履历。

```powershell
python scripts/report_manager_products.py INPUT.json --out NEW.json
```

输入：`{"asOf":"2026-10-03","managerName":"张坤","dossiers":[基金档案对象1,基金档案对象2]}`。支持1至500个不同代码，可不指定经理姓名。报告公司名称、任职记录、页码、披露日期和文件摘要自动保留。单只资料缺失单列；全池无法形成已核验关系时仍返回逐只待补清单，状态为 unavailable；不生成或宣称完整名单。

结果提供JSON、自然语言Markdown及HTML。报告仅确认至报告期，不因无离任日期认定今天仍在管。已知代码数量不等于独立策略数量；助理和不明确角色不纳入经理评价。此桥接不计算任期收益，历史业绩需另提供已核验净值口径，不能以渠道阶段收益替代。

支持有编号及无编号的正文章节标题；目录条目不作为正文证据。管理公司仍须来自明确的基金管理人列，不以托管人或其他公司名称替代。
