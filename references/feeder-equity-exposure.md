# 联接基金一层股票穿透

输入单基金档案结果，必须已经包含父报告、目标代码关系、同期间子报告、基金投资会计核对。只在目标全名唯一匹配基金投资行、基金投资金额合计核验通过、父子股票表勾稽通过、来源摘要与时点一致时计算。不按简称映射。

```powershell
python scripts/feeder_equity_exposure.py DOSSIER_RESULT.json --out NEW.json
```

父基金目标投资权重=目标投资金额/父净资产；间接个股权重=目标投资权重×子基金个股金额/子净资产，再加父直接股票权重。同证券命名空间、代码及股类合并，来源路径分别留存。

输出JSON、Markdown、HTML：目标投资权重、直接股票、目标底层股票、已知股票合计，完整逐股来源路径与原文位置；简报展示前20项，不截断JSON明细。股票之外的净资产部分标为未展开，不当作现金。期货名义敞口需另核验，本结果不是全组合风险暴露，也不是当前持仓或真实交易复原。

不支持股票敞口超过净资产的杠杆情形；缺资料、会计差额、目标简称未匹配、期间不一致或文件变化时停止，不生成看似完整的组合。
