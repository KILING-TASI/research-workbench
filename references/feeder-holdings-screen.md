# 联接基金股票穿透反查

输入已取得的单基金档案与持仓条件，重新核验父子报告摘要、基金投资金额及股票路径后筛选。仅支持已核验一层股票，不将其称为完整持仓。

```powershell
python scripts/feeder_holdings_screen.py INPUT.json --out NEW.json
```

输入格式：`{"dossier": 已保存的档案结果对象, "conditions": [{"kind":"holding","code":"300750","market":"CN-equity","minimumWeightPct":1}]}`。条件权重单位为百分比，基金代码与持仓证券代码分开。

已核验路径权重达到条件可确认命中；已知部分未出现或权重不足时返回资料不足，因为未展开资产可能另有暴露。非股票命名空间亦不会由股票表推断。输出JSON、自然语言Markdown及HTML，保留全部输入条件、逐项原因、原文位置和来源路径。不建议买卖，不代表当前持仓。

指定基金池输入：`{"asOf":"2026-10-03","dossiers":[档案对象1,档案对象2],"conditions":[持仓条件]}`。支持1至500个不重复基金代码。各档案须与本次截止日一致；某只缺资料或关联失败仍保留资料不足及原因，其他对象继续处理。覆盖率分母包含全部输入对象，不冒称全市场筛选。
