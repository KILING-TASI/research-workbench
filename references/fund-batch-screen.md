# 批量取数、对齐、指标与条件筛选

```text
python scripts/fund_batch_screen.py INPUT.json --out-dir NEW_DIRECTORY
python scripts/fund_batch_screen.py INPUT.json --out-dir SAME_DIRECTORY --resume
```
输入示例：
```json
{"codes":["110022","161005","005827"],"asOf":"2026-10-03","start":"2023-10-03","end":"2026-09-30","annualRiskFreePct":0,"conditions":[{"kind":"metric","field":"maximumDrawdownPct","op":"lt","value":30}],"rank":{"field":"returnPct","direction":"desc"}}
```

1至500个明确基金代码，主动触发获取，不做全市场扫描或后台刷新。逐只取供应商净值并校验身份；未知分红拆分拒绝计算。三年区间内成立晚、边界数据陈旧、历史不足对象保留错误和未知，不默默剔除后称为全池结果。原始资料、来源、获取时间及哈希保存；续采只重试失败/缺缓存项，成功缓存哈希变化拒绝续算，请用新目录重取。请求参数改变须新目录，不同任务勿共用同目录并发。

共同日期生成收益、回撤、年化波动及夏普。夏普为日收益均值乘252，减显式年无风险利率后除年波动；不是CAGR除波动。无风险利率默认0为模型假设。交易日完整性尚未官方核验，共同观测不证明无缺日；不规则间隔可能改变年化指标。供应商分红记录尚非官方全量事件核验，不宣称事前冻结样本。

输出逐只下载状态、指标计算错误、共同区间、screen-input.json、result.json及自然语言筛选简报。多维条件格式复用multidimensional-screen.md。主题标签、费率、评级、风险等级、行业、净流入和估值分位没有源时标缺项，不能假装已自动取得。此入口只有净值计算指标自动接通，不按基金名称制造主题或同类身份。不同风格基金不能直接作为同类优选；排名只属于指定池。


频率筛查：日度252年化只在至少3个观测、相邻日期间隔中位数不超过3日、最长间隔不超过14日时输出。未通过时波动率与夏普留空；累计收益与观测回撤仍按实际序列计算，可能漏掉未观测期间低点。此筛查不替代交易日历完整性核验，阈值不是统计可靠性标准。


输出增加可直接阅读的HTML简报，逐只显示名称、历史核心指标和筛选状态，条件未通过及数据不足原因分别列示。请求区间与共同观测区间分开展示；缺项标为未取得，不填零，不把满足历史阈值当作投资推荐。筛选条件在网络取数前校验。

排序结果同时写入可阅读报告：按资料日期、统计区间、指标口径和单位分组，显示组内序号；缺排序指标的对象单列原因，不因筛选通过而补造排名。不同组不合并名次。

续采版本：参数一致后，更新前将已存在的采集记录、筛选输入、结果及Markdown/HTML简报原样保存至versions/before-resume-唯一编号，manifest.json记录各文件SHA-256，collection.json保留previousOutputVersions指针。失败尝试也保留旧输出，不把存档视为旧结论正确性认证。单文件归档上限30MB；只有当前存在的文件进入快照，不补造未生成的旧报告。缓存现在按原始字节保存与验哈希，早期文本哈希缓存若不一致需另用新目录重取。
