# 统一标的检索

总入口research_pipeline.py --workspace 项目目录 --out 新文件 search 代码或名称 [--kind fund|etf|stock|bond|convertible|government-bond|credit-bond] [--online] [--limit 20]。独立security_search.py参数相同，但--out放在末尾亦可。

项目目录使用基金、ETF、股票已有市场目录；独立空目录可以--online取得东方财富检索候选。目录缺失明确标记，不声称独立安装自带全市场库。匹配返回代码、名称、品种、市场、来源、目录日期、核验状态和覆盖缺口。同代码不同市场/品种保留，多个候选不自动选定。基金份额类别不从末尾字母猜。当前没有官方证券主数据统一身份映射，跨来源同标的候选可能重复，保留方便核对。

转债、国债、信用债查询经第三方候选检索；Classify=Bond只证明供应商登记债券类，不按名称或代码前缀自动确认细分品种。requestedKind仅用户请求，不是已验证分类；不返回猜测条款、信用或可交易结论。实时行情和原文核验另行执行。

真实样例：110011基金、510300ETF、600036股票、113052兴业转债、019792 25国债19、名称24中信01（241423）均返回身份候选；红利ETF目录匹配80项并限制展示20。空查询拒绝，000001跨品种歧义保留。无推荐买卖。
