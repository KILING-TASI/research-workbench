# 从问题找到研究方法

轻量查询不加载完整方法集。五类任务按描述、解释、测算、估值、取舍组织：先回答当前问题，再按证据缺口扩展深度。31个申万一级行业和22种经营方式属于两个层级，不相加称53个行业。

```text
python scripts/framework_route.py --task explain --industry 280000 --depth standard
```

机读索引为research-framework.json，入口会核对所引用资料的摘要及路径。它返回该读的框架与实际入口，不自动取得数据或证明方法已经实现。公司比较读估值选型及可比池；盈利质量读回报分解；盈利情景读拆解规范；竞争优势继续复用research-methods中的证据与反证。

专业方法由各专业仓维护，本工作台只登记路由，避免再复制完整方法卡。数据、ETF轮动、REITs、财报、穿透、组合、规则、宏观、市场叙事和北交的计算范围各自保留。档案和历史方法页按需查阅，不每次加载。

方法卡按[机读索引](method-cards-index.json)统一问题、依据、数据口径、假设/算法、反证、已实现、未实现七段阅读字段；12张原卡与5项补充指引分别标记，不把索引数量当计算能力。
