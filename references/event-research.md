# 公告与新闻追踪

入口：research_pipeline.py events 输入.json；event-monitor 输入.json。沿用 --workspace 与 --out，输出不能覆盖首次依据。

```json
{"market":"CN","code":"600036","asOf":"2026-10-03","months":1,"refresh":true}
```

months=1或3个日历月，含起止日。CN六位代码自动请求第三方公告元数据，仅采集公告，不顺带获取整段行情财务。失败保留旧缓存与原采集时间；无缓存显示unavailable；空响应不能判定无公告。HK五位代码、US大写代码可分析提供的items，目前不自动采集。未使用交易所原文取代第三方目录，也未声称覆盖全部市场公告。

提供新闻/正文：items数组内每条包含id（可选）、title、publishedAt或date（YYYY-MM-DD）、text（可选）、sourceUrl或url、sourceType（可选）。可提供eventDate、validity、relatedSubjects、relatedIds。日期与主体输入声明不等于原文核验。金额与日期提及附原上下文，impactAmount未知保留null；计划/进展/完成分别标示标题含义。

分类支持业绩、减持、回购、诉讼仲裁、监管、订单合同、融资定增、分红、并购重组、担保债务、退市风险、治理人事。多标签允许冲突同时存在。优先级是固定规则研究线索，不是经验验证的重要性评分。fundamentalImpact默认待核查，不自动将利好/利空投射为股价涨跌。聊天分析需读取原文，指定收入、现金流、信用或治理影响方向，区分已知事实与假设；未有证据不能升格为利好利空。

更正公告保留独立条目与isRevision。relatedIds仅登记显式关联，未验证内容替代关系；问询函与回复、同一控制主体自动匹配尚未完成。仅重复相同ID相同内容去重，同ID不同内容报冲突；不同媒体同一事件的跨来源聚类尚未完成。

brief只汇总当前代码在asOf当天披露且已取得的事件，并非完整全市场今日简报。监控调用：
```json
{"result":{},"rules":{"keywords":["回购"],"eventTypes":["回购"]},"seen":{}}
```
result传入events完整结果；将返回seen保存，下次输入用于识别新增/变更。关键词筛选标题，事件类型筛选标签；两种条件同时设置则取交集。状态含市场+代码，保留历史已见项目，窗口滑出后再次出现不重复通知。此功能执行本地差异评估，不常驻运行、不发送消息。行业规则需另有核验过的公司行业映射，不猜测关联。

历史估值/股价/机构预期冲击复盘仍需事件首次公开时间、可比价格和基准、预测修订历史；本模块未实现该复盘，不用事后涨跌倒推因果。

## 已取得价格的事件日期复盘
`python scripts/event_price_review.py INPUT.json --out-dir NEW_DIR`。输入 archive（宏观/资产观测归档）、assetId、comparisonId、eventDate、eventSourceUrl。核对原始价格后比较事件前后5/20个共同观测间隔；日期和来源仍需另核原文及发布时间。交付价格变化与对照差额，不是因果效应或择时指令；不能替代估值、预期修订和实时资金资料。

事件前窗口截止于事件日期之前的最后共同观测，不包含事件当日收盘。事件后窗口以事件当日或其后首个共同收盘为基点；可能遗漏事件当日即时反应，不能称为完整事件收益。5/20指实际共同观测间隔，不是固定自然日。
