# 文档索引与版本

文档版本：1.49 · 更新日期：2026-10-08

[功能说明](current-capabilities.md)是现行功能总纲。首次了解产品先读该页；需要运行、复算或核查某项功能时，再进入对应参考。这里的版本号仅用于说明文档，不代表软件版本或验收评分。

## 各份说明的用途

| 文档 | 定位 | 什么时候读 |
|---|---|---|
| [SKILL.md](../SKILL.md) | AI任务识别与执行路由 | 判断用户问题需要哪条研究流程 |
| [README](../README.md) | 产品与安装入口 | 安装、检查环境和第一次运行 |
| [快速开始](quickstart.md) | 标准库首次体验 | 无账户、无作者目录跑通教学报告 |
| [日常简明入口](practical-entry.md) | 基金、表格与组合常用任务 | 通过少量参数生成现有资料研究报告 |
| [现行功能说明](current-capabilities.md) | 面向使用者的六类场景总纲 | 了解可以提出什么问题、会得到什么结果及使用条件 |
| [方法与参数索引](capability-reference-index.md) | 详细说明的导航 | 查找公式、输入、输出和特定场景限制 |
| [基金功能说明](fund-user-guide.md) | 基金研究的详细分支 | 了解产品比较、持仓、经理、费用等细节 |
| [统一脚本命令参考](six-workflows.md) | 常用命令与数据格式 | 实际调用统一脚本；命令数量不代表产品场景数量 |
| [26个研究场景映射](investment-research-scenarios.md) | 研究问题与工具的对应表 | 组合行业、公司、估值与投后研究步骤 |
| [专用脚本调用](integrated-topics.md) | 北交所、宏观指标与ETF轮动的执行参考 | 需要调用对应脚本时读取；代码分组不是产品功能层级 |
| [术语表](research-glossary.md) | 术语解释 | 遇到不熟悉的专业词语 |
| [验证范围与样本](validation-scope.md) | 有日期、有范围的验证记录 | 判断已有结果能支持什么、尚未验证什么 |
| [历史说明入口](legacy-instructions-20261002.md) | 已停用说明的保留链接 | 打开旧链接时找到现行文档，不用于执行 |

SKILL.md按用户问题选择入口，功能总纲按交付场景解释能力，两者对应同一组六类场景。26个研究问题是细分问题清单，不是另一套产品模块。资料核验与事件解读、研究档案与报告导出属于共用能力；深度报告与一页纸属于交付形式；modules及专用脚本属于执行结构。

参数规范说明当前接口；带日期的验收记录仅说明当时的样本和环境。遇到参数或范围冲突时，应核对现行脚本与对应规范，不沿用历史命令，也不把旧样本的成功状态当作本次取数成功。
