# 年报经理任职表提取

`python scripts/report_manager_tenure.py REPORT_DIRECTORY/result.json --out NEW.json`

输入为已保存且身份匹配的基金报告档案。核对PDF哈希，提取支持的六列表格：姓名、职务、任职/离任日期、证券从业年限自述和说明；合并跨页续行，保留全部页码与原文。输出自然语言Markdown及结构化记录。未找到支持表格明确返回缺口。

managers可经阅读职务上下文后用于manager_products.py的evaluationInput。表内可能包含经理助理，不未经确认直接当作经理；其他产品名称不自动映射代码。公司和任期净值仍由其他已核验资料提供。旧报告不能证明今天在管，证券从业年限不等于本基金任期，不保证全履历。日期冲突、重复同名记录和PDF变更拒绝静默处理。


新增有明确姓名/任本基金经理/证券从业年限表头的八列合并单元格布局，任职日期支持原文完整中文年月日；不是按列数盲猜身份。角色、页码和履历上下文仍保留，不把旧年报当最新在管名单。

角色区分在跨页职务文本合并之后完成：本基金经理、经理助理与不明确角色单列；其他基金的助理职务不改变本基金明确经理身份。助理和歧义记录不进入本基金经理任期评价，仍保留职务原文与位置供复查。
