# 上市公司三张报表

指定沪深股票代码、报告期起点和披露截止日，按请求获取资产负债表、利润表、现金流量表全部接口字段。普通企业接口失败时尝试公司类型对应的行业接口；不猜公司类型。

```text
python scripts/stock_statements.py --code 600519 --start 2025-01-01 --as-of 2026-10-05 --out-dir NEW_DIRECTORY
```

输出 result.json、三表说明.html/Markdown、各表全部字段.csv，以及响应副本与SHA256。JSON保留空值、报告期、披露日、币种和报告类型；不将累计值当单季，不自动换算单位。输出共同报告期和资产减负债减权益的差额。

完整指接口全部返回字段，不等于公告附注或每行原文已核验。合并/母公司口径与金额单位仍需原文核验。当前修订数据不等于历史冻结版本。失败分表报告，其他表继续；未知字段不填零，不覆盖已有输出目录。

真实试跑：600519和600036各取得2025Q1至2026中报六期三表；不能据此承诺任意公司均完整可得。暂不覆盖港美股完整三表。


### 换行版式与金融行业核对
原文核对支持有明确两期表头、同页且完整字段的金额换行，以及同页受限的字段名称续行；有明确附注列时识别中文附注编号。跨页、列归属不明或同名冲突仍保留缺口。银行营业总收入不静默替代营业收入，缺少营业成本也不填零；券商并排合并与公司报表未确认单位和列归属时不核验。现金流正负转换描述为净流入/净流出，不称为转盈/转亏。
