# 名称候选到历史条件研究

`python scripts/theme_research.py INPUT.json --out-dir NEW_DIRECTORY`；失败后使用同一输入和 `--resume` 续采。

示例输入：
```json
{"terms":["消费行业股票"],"exclude":["后端"],"maxCandidates":10,"start":"2023-10-03","end":"2026-09-30","asOf":"2026-10-03","conditions":[{"kind":"metric","field":"maximumDrawdownPct","op":"lt","value":40}]}
```

获取当前公开基金目录，冻结名称候选，再调用批量净值研究与共同区间筛选。输出自然语言研究摘要、候选清单、目录来源与哈希、逐基金获取状态、历史指标和缺口。基金份额未合并；名称匹配不是已核实主题。

maxCandidates默认30、最大500；超限不按代码截取，需缩小查询或改为指定池。续采校验原始目录哈希与全部请求参数，重新使用冻结候选，仅重试失败取数。参数变更使用新目录。当前目录不能代表历史事前候选；共同日期与供应商分红尚非官方全量核验。无名称匹配不证明该主题基金不存在。


输出增加可直接阅读的HTML简报，逐只显示名称、历史核心指标和筛选状态，条件未通过及数据不足原因分别列示。请求区间与共同观测区间分开展示；缺项标为未取得，不填零，不把满足历史阈值当作投资推荐。筛选条件在网络取数前校验。
