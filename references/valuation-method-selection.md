# 按业务与现金特征选择估值方法

先确认估值对象是项目、企业还是股权，资料可得日与估值日分别记录。以下是研究选型，不是方法自动可用或目标价输出。

| 业务特征 | 可以考虑 | 必要核对与容易误用 |
|---|---|---|
| 盈利与资本消耗较稳定 | 同业倍数、现金流折现 | 可比业务、盈利质量、再投资及终值；历史PE分位不是独立价值锚 |
| 强周期 | 正常化盈利情景、资产或现金流法交叉检查 | 利用率、价差、产能与周期位置；盈利高点的低PE不能直接判便宜 |
| 重资产 | 资产价值、资本回报与现金流交叉检查 | 资产质量、维护开支与ROIC；不因重资产就禁止PE，也不因账面值存在就认可PB |
| 银行与其他金融 | 资本、盈利持续性、资产质量及对应金融模型 | 不套普通企业营运资本和FCFF；寿险内含价值口径须对应披露版本 |
| 亏损或早期增长 | 量价、单位经济、盈利与融资路径的情景 | 销售倍数不能替代盈利兑现和现金消耗；资料不足保留参数缺口 |
| 有限期特许经营 | 明确剩余期限的现金流折现 | 期末处置和恢复义务；没有续期依据不能使用永续终值 |
| REITs | 项目现金流、资产价值、可比资本化率与分派的不同视角 | NOI、项目自由现金、基金费用和可供分配分别桥接；分派率不等于估值结论 |

配合[可比池](comparable-selection.md)与[回报分解](profitability-decomposition.md)。观点须有业务证据与反证，不按行业名字机械指定唯一方法。主题依据：[估值对象与现金流](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/background/valintro.htm)，本页为项目原创研究流程。
