# 公司与行业财务分析

复用 stock_statements.py 取得的三表归档，指定自然年季度末和公司分组。支持累计转单季、同比环比、经营质量规则信号、同口径分组中位数和中文HTML/Markdown报告。自动完整行业股票池仍未接通；Word及PPT导出可使用下述独立入口，排版需另行验收；原文页码及Excel工作簿用[公司池联动](company-report-workflow.md)，不自动判定经营原因。

## 调用

```text
python scripts/industry_financials.py INPUT.json --out-dir NEW_DIRECTORY
```

输入示例：
```json
{
 "period":"2026-06-30",
 "companies":[
  {"archive":"三表目录/result.json","metadata":{
   "name":"贵州茅台","group":"白酒指定池","classificationVersion":"用户分组v1",
   "sectorType":"general","scope":"consolidated","currency":"CNY","unit":"渠道原单位（未核验）"
  }}
 ]
}
```

AI根据用户的公司集合准备参数，不要求普通用户手填JSON。scope为consolidated或parent，sectorType为general或financial。范围、单位、分组版本须明确，不因接口名字猜公告口径。调用者声明与原文已核验分开。财务档案留存三表来源，输出保留各指标字段、输入报告期、披露日及档案SHA256。

## 算法口径

- 利润表与现金流累计值：第一季度直接取值，后续季度减同年上一季度累计值。必须有相邻两期；资产负债项目始终取期末存量。
- 同比用上年同季度单季或期末值，环比用上一季度；同比环比基数大于零才计算常规增幅。零/负基数标注转盈或亏损变化，不给误导的增长百分比。
- 比率：净利润/营业收入、经营现金流/净利润、购建长期资产现金/收入、负债/资产；非金融企业另算毛利率、销售+管理+研发+财务费用/收入。分母非正或字段缺失留空。
- 分组同时隔离行业版本、金融属性、合并范围、币种和单位。中位数逐项列有效与缺失样本数；不输出未经支持的行业总量或质量评分。
- 信号只提示应收增长快于收入、盈利但经营现金流为负；不能证明经营原因或财务造假。未触发不代表财务安全。
- 同期冲突字段留空；资料缺期不插值。追溯重述、会计政策、合并范围变化须原文核验，当前修订接口不是历史冻结版本。

## 交付与阅读方式

需要说明样本分化的经营原因时，读取[行业经营逻辑](industry-operating-logic.md)，按业务模式选择相应运营指标。分组中位数只能描述差异；原因判断另需经营证据，不能由规则信号直接生成确定性因果结论。

报告提供公司指标表、单季同比环比、分组中位数、有效样本数、规则信号及资料缺口。分组结果只代表指定样本，不直接代表全行业。

需要原文核对、经营原因解释或 Excel 底稿时，使用[公司池联动](company-report-workflow.md)。原文引句、公司表述、研究解释和待核实问题分别展示；数值一致不证明经营原因已验证。报告身份、单位或相邻期输入缺口仍会保留在交付状态中。


## 保存点评到 Word

`python scripts/export_financial_docx.py <输入.json>`，输入包含 markdownPath、markdownSha256、outDir（新目录）。需要 python-docx。从已保存中文点评保留全文及页码链接，复制目录内引用文件，生成可编辑 DOCX 和来源摘要。正文或引用变化先停止，不自动补造资料。支持六列以内的规则 Markdown 表格，导出为可编辑 Word 表格并保留空白、负数及单元格内来源链接。分隔行无效、列数不一致或超过六列时停止，不补零或丢弃单元格。合并单元格、嵌套表格和复杂财务模型仍使用 Excel 底稿。

生成文件不代表排版通过；交付前须渲染逐页检查。缺少 LibreOffice 的 Windows 环境无法执行现有渲染器，应保留为待视觉验收文件，优先交付已有 HTML/Markdown。PPT 可使用下面的正文导出入口。


## 保存点评到 PPT

`node scripts/export_financial_pptx.mjs <输入.json>`，输入包含 markdownPath、markdownSha256、outDir（新目录），可选 fontFamily。需要可用的 @oai/artifact-tool 演示文稿组件，通过 ARTIFACT_NODE_MODULES 指定组件目录；独立包不自带该组件。未提供组件时明确失败，不退回伪造格式文件。

生成 candidate.pptx、逐页预览、来源副本和导出记录。正文按主题分页保留，可编辑文字中的负数、百分比和PDF页码不拆开，相关引用进入每页备注。正文哈希变化或引用文件缺失时停止，暂不处理Markdown表格。保持原有资料缺口，不把格式转换称为新核验。

交付前检查最终PPT文件结构、文字与正文的一致性，逐页渲染检查溢出和裁切。预览与保存成功不替代最终文件验收；新增图表、完整行业材料和表格导出不在此正文转换范围。

负基数及零基数不输出普通增长率。负值变为零时按科目解释：利润为亏损归零、经营现金为净流出归零，财务费用等一般字段为负值归零；费用的负值变化不能写成公司扭亏。文字仅描述已取得金额的变化，不证明业务原因或未来趋势。
