# 常用研究术语

文档版本：1.0 · 更新日期：2026-10-05

本页解释[功能说明](current-capabilities.md)中的常用词。具体公式、输入和限制以对应的方法文档为准。

| 术语 | 通俗解释 | 阅读结果时注意什么 |
|---|---|---|
| 证券身份 | 证券名称、代码、市场、币种和份额类别的组合 | 同名、同代码或A/C份额不一定是同一研究对象；这里不指用户身份 |
| ETF | 在交易所买卖的基金，通常跟踪某个指数 | 指数表现、基金净值和交易价格是三种不同数据 |
| ETF联接基金 | 主要通过投资目标ETF来跟踪指数的基金 | 穿透需要联接基金持有目标ETF的比例，不能直接把指数权重当作全部持仓 |
| FOF | 主要投资其他基金的基金 | 逐层穿透要有子基金报告；缺失部分保留为未知 |
| MOM | 将资金交由多位经理分别管理的组合 | 未公开的内部持仓不能由公开基金报告推算出来 |
| IOPV | ETF盘中参考净值 | 是参考估值，不是可成交价格；时间点必须与比较的价格一致 |
| PCF | ETF申购赎回清单，列出一篮子证券和现金替代等要求 | 适用日期、现金替代规则与二级市场买卖不同 |
| 年化收益率（时间加权） | 将净值序列的区间增长换算成年化，描述产品自身的历史表现 | 要说明区间、分红处理和年化方法；不是账户实际赚到的金额 |
| XIRR | 考虑每笔投入、取出及其日期的资金加权年化收益率 | 反映现金流时点；不等于基金净值年化收益率，特殊现金流可能无唯一解 |
| 复权与总收益 | 复权处理分红、拆分造成的价格变化；总收益还需明确分红如何计入 | 复权价格代理不能自动视为分红再投的总收益 |
| 夏普比率 | 单位波动风险对应的超额收益 | 要对齐无风险利率、频率和年化方式，样本不足时不能强行比较 |
| 最大回撤 | 指定历史区间内，从阶段高点到随后低点的最大跌幅 | 改变起止日期会改变结果；不是未来亏损上限 |
| A/C费用临界持有期 | 在给定申购金额和费率下，两类份额累计成本相当的持有期限 | 费率阶梯和定投方式会改变临界点，不能套用统一天数 |
| Brinson归因 | 将相对基准的收益拆成行业配置、行业内选择及交互作用等贡献 | 必须说明公式版本、期初权重、行业收益、基准及行业分类 |
| 最小方差与有效前沿 | 在给定历史数据和约束下，寻找波动较小或收益风险组合不同的权重方案 | 属于历史样本下的模型结果，不代表未来最优配置 |
| 历史分块模拟 | 抽取连续历史片段并组合成模拟路径 | 保留部分短期联动特征，但未来仍可能出现样本中没有的情况 |
| FCFF-DCF | 把企业未来自由现金流折现，估算企业价值的方法 | 收入、利润率、资本开支和折现率等均需明确假设 |
| WACC | 企业债务和权益资金成本的加权平均值 | 用于匹配相应现金流的折现；不是一个固定通用利率 |
| 久期 / 凸性 | 修正久期近似衡量价格对收益率变化的一阶敏感度；凸性描述这种关系的弯曲程度 | 基础近似依赖收益率变化等假设，不能替代含权债券完整定价 |
| 行业分类版本 | 将公司归入行业时采用的标准及版本，如申万2021版 | 换分类可能造成表观行业变化，不能直接当成调仓或风格漂移 |
| 数据覆盖率 | 已知资料占目标研究范围的比例，如已披露股票市值占权益仓位的比例 | 必须列分母；覆盖率高不等于数据准确率高或预测更准 |
| 原文核验 | 将选定字段与取得的原文、页码和口径相互核对 | 核验通过只适用于该字段与文件版本，不证明公司财务真实性 |

“四周期”是按库存、设备投资、建设活动和长期结构变化组织宏观证据的框架。框架定义与实际可用观测分开列示，见[专用脚本调用](integrated-topics.md)。
