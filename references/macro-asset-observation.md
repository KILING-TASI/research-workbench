# 宏观观测与跨资产历史对照

请求“CPI、美债利率与科技股、长债、比特币怎么看”时，可先用本流程获取可复查观测。它补充宏观资料与资产历史窗口，不替代macro-indicator的国内指标和周期研究，也不继承其数据缓存。

## 完整调用

AI根据用户问题准备参数：

```json
{"start":"2024-09-01","asOf":"2026-10-05"}
```

```text
python scripts/macro_asset_observation.py collect input.json --out-dir new-macro-archive
```

按请求尝试FRED的CPIAUCSL、DGS10、DFF、CBBTCUSD，另取QQQ、TLT价格日线。接口不足两点时尝试Yahoo日线；留存初始请求及备用来源，不把报价当完整历史。网络或格式失败按序列记录，其他序列继续；不保证来源持续可用。归档原始CSV/JSON、请求、抓取时间和哈希。

```json
{"archive":"/absolute/new-macro-archive/result.json"}
```

```text
python scripts/macro_asset_observation.py build report-input.json --out-dir new-macro-report
```

输出JSON、Markdown、HTML。用户无需自行填写JSON。归档与报告目录必须新建，不覆盖旧研究。来源采用公开下载，不需要本流程收集用户API密钥。

## 已实现计算

- CPI季调指数最新观测及精确上一年同月的同比；缺上年同月则不计算，不取最近月份代替。
- 收益率和有效联邦基金利率的相邻有效观测差，以bp显示；不是变化百分比。
- 三项资产的30/90/180自然日历史价格变化，严格采用共同有效日期。起点取目标日之前最近共同日期，偏差大于7自然日留空；这是研究规则，非官方交易日历。
- 每项计算保留输入价格或指数、公式、来源哈希和代码哈希，可复算。报告披露实际区间、终点距截止日的天数与缺项。

2026-10-05验收取得3项宏观序列和BTC、QQQ、TLT价格观测；窗口基于此次实际归档，不能当成以后每次都有同样覆盖。

## 必须保留的解释

### 官方价格发布的评价步骤

用户要求解读国内CPI等价格发布时，先取得统计机构原始发布及口径附注，必要时另读同机构解读。沿用资料归档与结论绑定步骤，不把本节当作新增的全市场自动采集接口。同机构的数据与解释分别记录，不算两份独立因果验证。

1. 明确全国或地方范围、统计月份和发布日期，区分同比、环比和累计平均；新闻标题、检索摘要与原文表格分别核对。
2. 总指数与食品、能源、服务或核心指标分开看，分项与总量不同向时保留这种结构，不把总量回升直接解释为全部需求改善。
3. 官方原因、数值变动和研究假设分开。需求推动与成本推动对企业利润含义可能不同，需要销量、投入成本、售价及现金资料；单月价格不直接给出利率或股债方向。
4. 核对季调、基期轮换、分类目录、权数和调查范围。官方公布的平均口径影响不作为每个月固定调整额，不自行从公布同比中扣除；跨年同名分类不默认完全可比。
5. 将后续需求、成本和政策反应列为检验条件，明确连续分项、季调或传导证据缺口。消费价格统计分类不等于基金持仓行业分类或企业收入结构，消息关联不能直接换算组合损失。

每个关键数字、变化单位与口径说明绑定原文定位。归档网页可用报告内容验收的htmlLocator检查引句位置；检查不执行网页，不替代来源认证、因果判断或视觉验收。报告采用“有范围的判断 → 分项及竞争解释 → 改变判断的条件 → 已回答与缺口”的顺序。

CPIAUCSL是季调指数，用它计算的同比不冒充通常公布的未季调同比。DFF是有效利率，不是Fed目标区间或声明语气。所属期不等于发布日期；下载CSV不含每点发布日期，空白保留，不推定“当时市场已知”。当前修订历史不能用于事前事件预测验收。

QQQ/TLT价格未核实分红、拆分和复权，不是总收益。BTC每天交易、ETF有休市，FRED的Coinbase说明采用17:00 PST观测；共同日历日期不等于与ETF同步交易时刻；不把周末BTC数据填到ETF。币种不一致阻断价格对照。没有足够共同历史就留空，不拿纳指等替代QQQ。

宏观观测和资产变化并列展示，不做因果归因，不判定四周期阶段，不输出可靠度评分、涨跌预测或配置权重。用户指定情景可另接已有组合模型，不能用观察报告自动产生交易建议。

指标定义参考：[CPI](https://fred.stlouisfed.org/series/CPIAUCSL)、[10年国债收益率](https://fred.stlouisfed.org/series/DGS10)、[有效联邦基金利率](https://fred.stlouisfed.org/series/DFF)、[比特币美元报价](https://fred.stlouisfed.org/series/CBBTCUSD)。

## 原始来源文件绑定

FRED CSV和备用行情响应保存相对文件名及哈希。报告生成前检查原文件存在且哈希一致，变化时需重新取数与解析。没有可绑定原件的旧渠道档案标为 raw-source-not-bound；这不是行情已获原文核验。文件哈希核对不证明逐点发布日期或定价时刻。

已绑定的FRED CSV与备用ETF响应会重新解析，逐点核对日期及值；原件不变但归档观测被改写时拒绝生成报告。已验收档案六条序列均完成该对照。逐点一致仍不证明历史公布时点可得，也不将价格变化升级为含分红总收益。

可选 transmissionHypotheses：每项包含已取得宏观序列的 factorIds、机制文字 mechanism、非空条件列表 conditions、非空反证列表 counterEvidence。输出绑定最新观测、所属期与来源哈希；仅为研究假设，不证明因果、不自动判周期、不预测价格。未取得序列不能用作观测依据。

取数可指定 seriesIds：支持 INDPRO（美国季调工业生产指数，2017=100）、UNRATE（美国季调失业率）及原有指标。默认沿用原有四序列。指标是修订历史观测，所属月不等于公布日期；活动、就业和通胀均取得也不自动证明周期阶段。

assetIds 可设 [] 仅取宏观序列，或选择 QQQ/TLT/GLD/IWM；默认仍取两项。未请求资产不属于失败。工业生产同月同比按季调指数计算，不是GDP增长率；缺少去年同月观测时不计算。

月度观察另列 monthlyAlignment：按共同所属月展示指标，不补缺期。共同月份不等于共同公布时间，修订历史不能当事前已知数据；最新月份不同须并列说明，不自动合成周期分值。

monthlyAlignment.history 保存最近最多12个实际共同月份与逐项原始观测。共同月份不保证连续；表中缺月不插值。此为按请求触发的历史观察，不是后台景气监控或周期预测。

月度对照同时列出观测范围内所有未能共同对齐的月份及缺失序列（monthGaps），包括所有序列都缺失的月份；isContinuous 只说明这个观测范围是否断档，不证明发布日期同步。指数和价格必须为正，窗口外数据不参与报告，无效档案在输出前阻断。

近期对照 recentObservationWindows 按1/5/20个实际观测间隔计算，分别保存起止日、实际自然日、输入与公式。利率变动用bp，失业率用百分点，指数用相对变化。不将观测间隔称交易日或固定天数；不足时留空。仅主动请求运行，不后台刷新。

日度利率与资产同窗口对照：对已选DGS10、DFF与资产价格取共同日期，计算1/5/20个实际观测间隔的利率bp变化与价格收益。缺少任一所选序列时窗口留空；不补节假日，月度CPI不混入。共同日期不代表同一时刻，不能据此认定因果、事前信号或宏观解释已验证。

## 指标定义与传导引用

报告生成前检查已支持序列的单位、角色与频率。DGS10/DFF原值为百分比，差分乘100才得到bp；不能将已换成bp或小数的档案沿用此计算。QQQ/TLT本入口为美元价格，不接受把币种标签改成人民币代替汇兑。修改口径需重新准备独立数据，不能仅改标签。输出 `seriesContracts` 记录定义检查；它不证明逐点发布日期、同步定价或第三方数据准确性。

传导假设可增加 `assetIds`，仅引用本次实际取得的资产，不用替代标的补缺。每项 `assetObservations` 保留日期、币种、价格口径、定价时钟、来源哈希与核对状态；与宏观观测不同日期时明确标注。价格变化不等于总收益，假设也不变成已验证的因果解释；统一研究结果保留这些缺口。


## 商品价格观测

seriesIds 可选 DCOILWTICO（WTI库欣原油现货，USD-per-barrel，daily-business）和 PCOPPUSDM（全球铜基准月均价格，USD-per-metric-ton，monthly），assetIds 可设为空列表。由 FRED CSV 获取原始响应，重新解析并核对哈希及观测，分别列所属期、原始单位和实际观测间隔变化。铜不是日度期货；原油不是ETF净值。WTI历史非正基数不计算相对变化；铜基准价须为正。

例：{"start":"2025-01-01","asOf":"2026-10-05","seriesIds":["DCOILWTICO","PCOPPUSDM"],"assetIds":[]}。沿用 collect/build 命令和宏观观察统一模板；统一上下文采用 price_only。

逐点发布日期、原始发布版本及库存供需尚未核验。没有产量、消费和库存证据时不输出商品周期判断、供需缺口或未来拐点。定义来源：[WTI](https://fred.stlouisfed.org/series/DCOILWTICO)、[铜](https://fred.stlouisfed.org/series/PCOPPUSDM)。


## 美国原油库存

seriesIds 可增加 WCESTUS1：EIA 美国周度原油期末库存，不含SPR，unit 为 thousand-barrels，frequency 为 weekly。主动获取[官方历史网页](https://www.eia.gov/dnav/pet/hist/LeafHandler.ashx?f=W&n=PET&s=WCESTUS1)，校验完整标题、年月行与日期/数值列配对，留存HTML与哈希。网页布局变化、范围改变、无日期数值或重复统计期时拒绝猜测。

沿用 collect/build 及宏观统一模板。原始网页重新解析后比对每条观测；报告列最新库存、较前一个有效统计期的变化（千桶）和实际观测间隔变化。空值不填零，不推定缺失周的数据。统计期是期末日期，逐点发布日期未核验，当前修订网页不证明历史时点已可知。单项库存不代表全球供需平衡，不能据此确认原油周期或预测价格。

GLD与IWM作为新增美元ETF价格样本，分别用于黄金相关ETF和美国小盘股票ETF观察；不以其价格替代黄金现货或全部小盘股票。不宣称报价身份之外的持仓、费率和跟踪质量已核验。二者沿用原始响应留存、备用日线和逐点重解析，默认资产仍为QQQ/TLT。

共同资产窗口不足时，单列各项实际有效日期的历史窗口；缺失资产仍显示未计算，不从共同池静默删除。单项窗口起止日期可能不同，不用于直接排名或同期优劣判断。JSON同时保留individualAssetWindows与严格共同assetWindows。

日度利率与资产共同观测窗口保留最长相邻自然日间隔。超过7日标为稀疏观测并登记研究缺口，只展示已有端点变化；7日以内也不证明交易日历完整。此阈值是透明研究规则，不补造缺值或改变原始日期。

## 汇率历史观察

主动取数可在 `seriesIds` 中选择 `DEXUSEU`、`DEXCHUS`。前者为每欧元对应的美元数，后者为每美元对应的人民币数。来源为美联储 H.10，经 FRED 提供：[欧元报价](https://fred.stlouisfed.org/series/DEXUSEU)、[人民币报价](https://fred.stlouisfed.org/series/DEXCHUS)。

报告展示实际观测日期及 1、5、20 个观测间隔的变化，缺值不补。直接报价变化为期末汇率除以期初汇率减一；反向报价变化为期初汇率除以期末汇率减一，不能简单反转正负号。

这些是纽约中午买入价观测，不是即时可成交汇率；逐点首次发布日期未核验。不自动折算资产总收益，也不包含换汇点差或费用。

涉及制度、条款、专业方法与解释时，使用[适用依据规范](research-basis-standard.md)，核对范围、版本和原始依据；规则核对不替代本场景计算或内容验收。


## 季调与严格环比

已支持序列登记季调定义；输入`seasonality`与其冲突时拒算。定义登记不证明原始来源已独立复核。月度`monthOverMonth`仅匹配上一日历月，缺基数留空，同月多个观测拒算；百分数指标差值输出百分点，其他正基数输出相对变化。报告同时保留观测间差值，后者不能改写为环比。当前修订序列仍不代表历史披露时点可知数据。


报告先交付严格月度对比支持的主要观察，再列观测依据；缺环比输入时明确不作月度判断。共同月份与各项最新月份分别说明，不能拼成同步经济状态。口径提示只保留本次所选序列适用项；总结不输出周期分类、政策预测或资产配置指令。

## 政策公布与执行时钟

政策原文核对时分别登记公布日、生效日与指标观测所属日。`policy_original_reading.py` 的 clocks 支持原文明示的英文月份日期；effective-date 必须有与该日期相连的 Effective 措辞，不把英文发布日期自动归为生效日。引句定位只证明文字存在，不证明当前有效性或政策传导。

目标利率区间、有效成交利率、准备金余额利率是不同工具。比较政策幅度与观测幅度时记录前后日期及差分公式；日期和幅度一致不能替代资产因果检验。网页仍须确认唯一正文容器，不能为取到日期而静默使用整页导航文字。
美联储该版执行网页可用唯一 container__main 容器归档；此容器也含面包屑、标题和更新时间，只核对明确引用的执行段落，不从整页文字推断公布或生效时间。页面改版后重新确认容器，不默认沿用。


主要ETF日线渠道现在保留成功响应的原始UTF-8文本、原始字节哈希及请求记录。报告生成前核对请求证券映射和窗口，并从原始JSON重解析OHLC/收盘价，与归档逐点比较；不会用重新序列化的payload冒充原始响应字节。旧档案未留原始文本时仍标raw-source-not-bound，不追认原件核验。该检查不证明交易所分类、分红复权、时钟或投资因果。

事件复盘的已知信息时点：见[宏观网页标注时间核对](release-clock-review.md)。仅比较已归档同站点标注，不认证首次公开或实际可获得时间；晚出解读不提前纳入。
