# 收益风格观察（RBSA）

fund及benchmarks可附已确认name，报告显示名称与代码，不自动猜名称。benchmarkRole可声明product-proxies（产品收益代理）、user-selected-not-verified（用户选择未核适用，默认）或declared-style-indices（输入声明风格指数）。三类都不自动认证官方适用性；产品代理报告在顶部说明拟合权重不是资产配置。

用户要求用净值分析风格关系时使用；不替代披露持仓，不以R²或拟合权重判断违规。方法采用[Sharpe原文](https://web.stanford.edu/~wfsharpe/art/sa/sa.htm)的约束风格拟合思想，代码独立实现，没有复制未明确许可项目的实现。

调用：`python scripts/returns_style.py INPUT.json --out-dir NEW_DIR`。依赖已有numpy；不新增scipy，不联网，输出原输入、结果JSON及自然语言Markdown/HTML。

输入顶层asOf、currency、frequency（daily/monthly）、fund、benchmarks，可选window、step。fund及2至5个基准均含code、currency、basis=total-return、sourceUrl和history列表，每项date/value。主体唯一，币种一致，日期严格对齐，不插值或错位猜测。月度逐月连续；日度至少120组收益、月度至少24组，运行门槛不是统计可靠性保证。滚动window不小于相应门槛，step为正整数。

AI先按用户问题选定基准并取得同口径总收益序列，再准备输入；普通用户无需手填JSON。没有基准只凭基金净值不能运行。QDII必须确认净值所属交易日、币种及套保口径，不能将公布日期直接等同美股T-1收盘。日历完整性与原文真实性仍须另核。

拟合权重非负且合计1，最小化中心化残差平方和，等价于样本残差方差最小。R²按1−残差方差/基金收益方差记录，可为负，不截成0以制造拟合良好；平均残差另列，不称经理alpha。输出全样本及滚动结果，窗口权重标准差只是描述，不是显著性检验。权重识别提示检查加入合计1约束后的设计矩阵秩：两基准收益成比例不必然造成无法识别；真正重复基准仍提示可能不唯一。秩检查不替代条件数、误差敏感性或统计可靠性检验。

这不是样本外预测，缺少独立样本时保留未验证范围。基准池、窗口、市场状态、汇率和估值滞后都可能影响结果；不把R²下降自动写成基金转向港股/A股。主题基金80%规则是持仓与合同口径，不能用拟合权重直接判定合规。

有限真实试跑：005827对000248、000191、000216产品收益代理，81个月度收益、9个滚动窗口，选定池样本内解释度约75.73%。独立0.5个百分点权重网格复算未发现比求解结果更低的残差方差。这只验证指定真实序列上的数值目标，不认证风格基准适用、实际资产配置、分红完整性、QDII时差或样本外能力。可以通过sourceScope在报告顶部声明代理产品及数据限制。
