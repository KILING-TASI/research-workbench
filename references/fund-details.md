# 指定基金统一明细获取

```text
python scripts/fund_details.py --code 110022 --as-of 2026-10-03 --out NEW.json
```
直接访问第三方公开净值资料，输出JSON及自然语言Markdown。也可--raw 已保存的供应商JS资料.js离线解析（只提取JSON变量，不执行JS）。网络失败抛出错误，不编造或覆盖已有结果；旧文件须由用户或其他缓存采集入口保留。此入口不自动后台刷新。

取得单位净值、1/3/6/12/36个月实际区间收益、年化风险、资产配置与持有人结构。阶段起止按实际观测显示；252交易日是年化假设，没有完整交易日校验。序列附分红/拆分说明，未知事件阻止对应收益计算；能解析不代表全部事件官方核验。

经理简介、渠道申购费、最低金额、股票与债券代码为线索，不等于核验后的完整任期、合同费率或持仓。未提供日期的字段不能作为历史截止日事实；原始离线资料仅记录本次处理时间，不冒充获取时间。资产配置内净资产单位未独立核实时保留供应商原值，不转元、不进入规模排序。机构/个人/内部持有比例不要相加重复计算。

当前修订历史不代表时点可得输入。合同、正式基金类型、成立日、完整持仓、基准、费率及经理任期继续走原文核验模块；本入口明示缺项，不对任意基金宣称完整尽调，不输出供应商不透明星级和能力评分。基金货币类型无普通单位净值时不套用权益净值模型。


阶段区间覆盖：输出请求起点与实际起止日。起止边界缺口超过7个自然日时，不把不足历史或陈旧净值当作完整阶段指标；明确列出起止缺口及容差。该容差用于筛查，不证明交易日序列完整，也不自动把长假当缺失。


频率筛查：日度252年化只在至少3个观测、相邻日期间隔中位数不超过3日、最长间隔不超过14日时输出。未通过时波动率与夏普留空；累计收益与观测回撤仍按实际序列计算，可能漏掉未观测期间低点。此筛查不替代交易日历完整性核验，阈值不是统计可靠性标准。

## 关联经理报告证据
可加 `--manager-report 已归档报告结果.json`。仅接受同基金、报告所属日及披露日不晚于研究截止日的报告；重新读取PDF并核验摘要，提取经理、助理及歧义角色。经理任职记录与渠道姓名分别展示，不将旧报告延伸为当前在管证明。PDF缺失、摘要不一致或基金不匹配时停止，不静默省略原文核验。

## 关联完整股票持仓
可加 `--holdings-report 已归档报告结果.json`，与经理报告选项可同时使用。要求同基金、截止日前披露、完整股票表及既有勾稽已通过，并重新核对所保留PDF摘要；不接受仅前十大、会计差额未解释或文件已改变的结果。交付股票明细、市场命名空间、占全基金净资产比例、原文位置及来源。不把非股票剩余比例视为现金，不将全基金规模按A/C份额重复累加。

## 指定池批量明细
`python scripts/fund_details_batch.py INPUT.json --out-dir NEW_DIR`
输入示例：`{"asOf":"2026-10-03","requests":[{"code":"110011"},{"code":"161005"}]}`。最多50只、代码不重复。各项可提供 `raw` 已保存渠道JS、`managerReport` 与 `holdingsReport` 已归档结果路径。逐只保留原响应、明细及失败原因；一只失败不停止后续，关联证据失败不能标为完成。各只阶段区间不同，不能据此称共同区间排名。无后台刷新，不覆盖旧目录。

## 明细结论与币种缺口
报告先说明实际可计算窗口的收益与观测回撤，再列资料。净值币种未经独立核验时保留未知，不默认人民币；维度无单位的收益率不证明跨币种金额可比。没有合同基准或可比同业时，不输出优于同类判断。分类日期重复、同名字段冲突与结构异常停止解析，空分类明确列缺口，不填零。
