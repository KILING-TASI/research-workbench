# 再平衡日常调用与费用口径

更新日期：2026-10-09。高级参数按用户明确要求准备，不要求用户填写JSON。

使用start.py rebalance --input 已对齐历史与费用.json --out-dir 新目录计算并交付阅读报告。AI从既有组合历史按用户要求准备费用和频率，不要求用户填写JSON；缺少费用时先确认，不能当作免费交易。结果保存输入、代码和区间，可用同一入口--continue-from 上次目录另存重算；改费用或频率时提供新的--input，不改旧报告、不联网。依赖Node.js在PATH中，缺依赖保留可读失败说明和有效输入，安装后接续。场外基金不能将通用佣金模型当作实际申赎成本。

再平衡接续可直接修改已确认参数：--every-observations 10、--commission-pct 0.02、--minimum-commission 5、--spread-bps 4、--slippage-bps 2。只修改明确提供的字段，其他历史与假设沿用；0是显式零值，不当缺项。百分数0.02表示0.02%，价差/滑点使用bp；观察期频率不是日历月。已有逐资产同字段费用时拒绝统一替换，需明确新费用输入。

按月研究可指定--rebalance-schedule month-change：新月份第一个有数据观察日收盘形成信号，下一观察日收盘执行。仅适用于日频输入；不预看下一月日期来回填上个月月末成交，也不承诺完整交易日历。--every-observations显式切回观察期规则，与month-change不能同时指定。

再平衡追问生成调整前后比较，先核对旧输入与结果关联及其他研究条件，再对照定期方案收益、回撤和扣费变化。历史、权重、本金等变动时不称参数调整效果；费用与频率同时改变时不拆分单因素贡献。旧结果不可读时保留本次成功报告，并说明无法对照，不强行失败整个研究。

再平衡输入可附scopeNotes文字列表（最多20项），把本次资料与执行限制带到报告前部及保存结果，明确为输入声明、非独立认证。例如只有ETF基金净值时写清不是成交价格回测，缺分红拆分完整核验时不能默认为复权完整；不把净值代理包装成实际成交效果。

再平衡计算失败时，阅读入口给出人可读的原因和下一步；技术堆栈另存计算诊断.txt，不进入正文。有效参数修改在依赖缺失或计算失败时保留到输入，便于接续；无效修改不冒充已应用。不把未满足的约束放宽成成功结果。

分阶段观察使用--split-date YYYY-MM-DD，须为共同历史观察日。前后段各从相同本金和权重重新起算，共享边界价格但收益区间不重复；规则/费用不在段间优化。少于四个价格点拒绝。它是事后历史分段对照，没有事前参数与数据冻结证据时不能称样本外验证或连续账户。原输入、范围限制与分段结果随报告保存。

再平衡资产输入可保留已取得的name，不根据代码猜名称；名称随保存请求进入报告检索，来源段显示名称+代码和可点击链接。名称只是输入身份信息，不能代替公告核验；旧报告没名称仍按代码检索。

费用影响可选--cost-reference（--no-cost-reference关闭），用相同历史与规则计算佣金、价差、滑点和方向税费全部置零的反事实路径。报告分列累计支付成本与零摩擦减原方案的期末财富差；费用可能改变权重偏离触发，不解释为固定交易清单下的单项费用贡献，也不代表现实免费成交。
