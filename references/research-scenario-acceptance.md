# 投研场景验收规范

按 [场景用例](research-scenario-cases.csv) 逐项执行；当前可调用能力及资料边界见 [资料范围](current-capabilities.md)，具体参数见 [六类入口](../SKILL.md)。用例登记、入口可找到和测试通过均不替代本次研究的业务验收。

## 执行与记录

每项留存用户问题、实际回答、输入与参数、取得的资料及其日期、原文位置、计算结果、缺口、判定和原因。资料获取、计算、原文核验分别记录；当前资料无法取得时说明缺口，缓存不冒充最新数据。

分别评估业务结果与输出边界。业务状态使用通过、部分、未通过、未执行；输出边界使用通过、未通过、未执行。诚实留缺可通过边界检查，但缺少问题要求的统计或计算时，业务结果仍为部分或未通过。不得以关键词扫描替代证据与专业核对，也不把否定句“不能保证收益”误判为收益承诺。

## 证据与口径

- 每个关键事实核对来源、日期、单位、样本、共同区间及计算方法。第三方不标官方，模型计算不标实测，资料下载不标全文已核验。
- 区分事实、公司陈述、研究解释和显式假设；研究建议或待核实问题不混成已完成结论。免责声明不补足证据。
- 比较必须保留币种、分红、基准、分类版本和时间区间。指标缺失不填零、不补造；行业变化不自动认定价值/成长漂移。
- 历史频数需报告样本量与不确定性；交叉统计提示小样本和多重比较，不将历史统计转成未来概率或因果结论。

## 连续追问

有连续组的用例按轮次执行。后轮保留已知对象、持仓权重、资金、期限、假设、来源日期和缺口；新信息改变前提时记录变化依据。单轮通过但上下文承接失败，整组不通过。每轮单独留证，不能用末轮免责声明抵消前轮越界。

筛选迭代逐条列出满足、不满足、缺证据的条件，不因追加条件丢失原规则。用户说“四维”但只提供三维时说明缺项，不静默改题。后续追问不得转成加倍买入、卖出或申购操作指令。

## 专项核对

| 场景 | 必须核对的内容 |
|---|---|
| ETF与基金比较 | ETF可为股票、债券或商品等类型；规模不等于流动性，同赛道不等于同指数。指数成分集中度及调样频率与基金实际调仓区分。净值、指数估值、份额变化现金流代理分列。 |
| 组合与压力模拟 | 缺必要参数时给公式或明确条件，不捏造波动、回撤。确定的逐资产冲击无需另造相关性；联合路径模拟须说明分布与相关结构。一次冲击损益不等于未来最大回撤，加入固收加不必然降低波动。 |
| 历史回测与因子 | 实际运行的回测、历史统计与假设模拟分别标注；未运行不生成因子数值或有效性断言。残差不自动归为经理能力，历史估值情景不冒充未来收益区间。 |
| 宏观传导 | CPI上行与动能弱不足单独确认滞胀。共同宏观暴露、流动性、杠杆等可影响相关性，观察到共变不证明传导因果。 |
| 北交申购与现金 | 按当期公告核对网上、网下机制；比例配售不套用抽签概率。资金需求按冻结窗口的重叠峰值，机会成本按金额与自然日占用计算，标年化基准。不假定所有申购永久互斥；获配不等于获利，保留破发及卖出成本。 |
| 债券与可转债 | 纯债价值为模型估值，不是兑付保证；条款、利率、信用及成本所需数据分别说明。不把基础现金流计算当完整含权或违约恢复定价。 |
| 财报与公司风险 | 恒等式勾稽错误与财务指标背离分开，均不直接判定造假。未核验担保仅列待查，不断言存在；单位、合并范围、报告版本与支持字段范围必须明确。 |

## 报告验收

面向用户用自然语言说明发现、依据、影响和缺口，技术命令、内部进度和历史建设决策不进入报告。逐结论披露适用范围，不机械堆叠警告；历史表现不代表未来，研究结果不构成买卖指令或收益承诺。

HTML与Excel分别检查保存内容、来源链接、公式和视觉排版。内容或公式检查不能替代视觉验收；限定字段匹配不能扩大为完整三表、全文研究或全市场覆盖。研究档案保留参数及方法版本，口径改变时禁止无说明直接跨期比较。
