# 申万一级行业研究框架（SW2021）

适用于按申万一级行业组织公司、行业样本或已知持仓的研究。一级行业用于导航，实际分析仍按业务分部及二级/三级经营方式展开。以下覆盖SW2021的31个一级行业，**覆盖的是研究方法，不是31行业实时数据、成份股或真实验收覆盖**。

行业名称及分类代码依据[申万官方新旧分类对照表](https://www.swsresearch.com/swindex/pdf/SwClass2021/2014to2021.xlsx)的“新旧对比版本2”新版列核对。六位代码为分类代码，不是行业指数代码。分类版本固定为SW2021，不宣称永远最新；若用户指定其他版本，先核对对应官方代码表，不自动改写。

## 使用方法

1. 确认行业及版本；公司归属需有明确分类证据和适用时点，不按公司名称猜测。现有股票原表可能存在多条历史记录，沿用[原表核验](sw-classification-archive.md)的冲突和有效期限制。
2. 选择下表相应行，按实际业务拆分；多业务公司可复用多个框架。优先读取已取得财报的分部、运营及现金信息，再按需获取公开行业资料。
3. 对每个研究问题形成“观测事实→驱动解释→现金/风险影响→反证→下一项资料”，使用[研究判断方法](research-methods.md)。已有业务细节见[经营逻辑](industry-operating-logic.md)，不默认加载所有行业。
4. 同业比较先核对业务模式、单位、期间、范围、会计和分类版本；样本不齐只描述指定池。一级行业不同子业务不能直接用同一倍数或运营指标排名。
5. 指标未披露则列缺口与影响，不为填满框架编造数据、行业评分、阈值或预测。跟踪指用户主动请求后的核查，无后台监控承诺。

## 交付和跨行业应用

行业报告先解释本次样本的关键分化，附业务、指标口径、证据及未知项，不为31行业生成统一“景气分”。研究基金/ETF时标明已披露时点、持仓覆盖与分类证据，未知部分保留；一级行业指数不能替代真实组合。

业务经营风险与市场风险分开：某行业需求改善不保证估值提高或资产上涨。宏观传导要经价格、需求、融资或成本路径验证。行业冲击参数由用户或明确研究假设提供，不由本表自动生成。

## 方法检查场景

- 综合企业缺分部现金：保留资本配置与分部价值缺口，不从行业代码生成统一估值。
- 非银样本同时含保险与证券：分业务和指标比较，不对全池套NBV或普通企业毛利率。
- 石油石化油价上涨：同时核查上游实现价格、炼化价差与库存，不判全行业利润必然增长。
- 社会服务酒店与餐饮：分别使用入住率/房价与同店/客单，不能用酒店指标解释餐饮。
- 农林牧渔缺单位成本：售价变化可描述，盈利改善仍待验证。
- 公用事业中的水电与燃气：来水与采购气价分别取证，不套相同成本驱动。

本表的方法写作、名单核对与真实研究验收分别记录；完整名单不证明全部行业的数据链或报告已真实验收。
