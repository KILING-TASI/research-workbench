# 从研究问题到可复核判断

## 先确定交付层级

单字段查询直接回答，不套深研流程。用户要求深度研究、买方研究或系统评价时，按本流程组织工作，结合[深度研究交付标准](research-depth-standard.md)验收。

|交付层级|实际内容|不能冒称|
|---|---|---|
|资料核对|取得资料、身份和口径、数值及原文位置|经营原因或投资逻辑已验证|
|研究初筛|跨期变化、主要矛盾、有依据的有限解释、关键缺口|完整公司深研或投资价值评价|
|专题研究|围绕一个核心问题追踪业务证据、替代解释、财务兑现及反证|尚未研究的全部维度也已完成|
|完整研究|核心业务、盈利及现金驱动、竞争和风险均有实质证据；需要价值判断时具备对应价格与估值分析|数据或预测准确率、确定的投资结果|

不能仅把十二节展开、增加风险清单或改用买方标题，就升级交付层级。估值不是每种研究都必须计算；但缺价格、盈利假设或适用模型时，不完成投资价值和安全边际判断。流程状态记录在研究档案；报告用自然语言说明结论范围，不展示内部命令和维护轮次。

## 主流程：先建立问题，再组织证据

### 1. 定义研究任务

复用会话中的对象、截止日和窗口。明确用户要了解什么，以及什么结果会改变判断，例如“高增长为何现金流出，是否影响增长持续性”。分清事实描述、原因解释、条件测算与投资逻辑复盘。没有用户持仓、期限和风险约束，不推导适配性或配置建议。

批量研究采用两步：先逐只初筛，找出需解释的矛盾，再按用户范围展开专题或深研；不能为31只机械复制相同段落后声称完成31份深研。不暗中删掉失败或不利样本。首次假设、支持证据和反证条件可用[投资假设档案](buy-side-thesis.md)保存。

### 2. 选择经营或产品框架

公司先确认实际业务和收入构成，再用[行业经营逻辑](industry-operating-logic.md)选择量、价、成本、费用和资本占用变量。申万一级分类是导航，不替代细分商业模式。银行、券商、地产、工程、平台与周期企业分别使用对应口径。

基金与ETF先确认份额、管理方式、基准、指数与分红口径；组合先确认真实金额或权重、日期和交易资料。宏观先确认国家、指标所属期、发布日期与版本。不同研究对象的具体链路见下文，不把公司模板用于所有资产。

### 3. 将结论拆成证据任务

围绕核心问题建立工作表：`拟回答的判断｜所需资料和期间｜支持证据｜反对证据｜来源及位置｜口径与核验状态｜缺口影响`。先列会改变判断的关键资料，再列补充资料。缺销量就不能拆量价；缺应收、存货及应付款就不能解释现金占用；缺独立市场资料就不能宣称公司领先同行。

资料来源、取得时间、披露日期和版本分别登记。全文解析只是得到可阅读文本；关键词定位只是帮助查找。判断是否有证据要阅读对应章节、前后文和表格附注，不只摘关键词附近一句。

### 4. 获取、校验与有限恢复

使用已接通入口，按问题获取三表、报告、业务分部、事件或产品数据。缓存合格则复用；失败逐项记录，不覆盖旧结果。目录失败先检查窗口、名称和版本，可转公开原始公告链接或用户文件；显式链接不是目录元数据已认证。可用路径仍失败则说明缺口对哪项结论造成影响，不反复无效重试、不填造数据。

先核证券、报告期、合并范围、单位币种、表头、重述和可比列。公司单季分析涉及的累计输入都在核对范围内；关键论断依赖单季同比时，使用已有verifyQuarterInputs链路核对对应各期，不能只核本期半年报。拿不到依赖资料时将该论断限定为渠道计算观察。

### 5. 计算并建立变化解释

计算保留公式、输入、期间与来源；缺值不作零，范围不一致不混算。公司分析依次看收入、毛利、费用、减值和非经常损益，再看营运资本、经营现金和资本开支。基金看共同窗口、基准超额、风险及持仓贡献；组合看收益与风险来源，未知敞口单列。

数值桥能计算时列覆盖贡献及未解释残差，不能计算时写清已确认的业务变化与未知贡献。需要分部、竞争或同行比较时先补对应证据；历史稳定、净利增速和正现金流都不单独证明护城河。

### 6. 判断支持与竞争解释

每项核心发现说明：发生了什么 → 哪些直接证据支持 → 如何影响盈利、现金或风险 → 还有哪种解释 → 什么材料会推翻判断。公司解释和研究解释区分；管理层指引和券商预测不是实现值。独立性按底层来源判断，转载不增加证据强度。能确认的事实直接说清，未知原因不要无限稀释事实结论。

买方侧增加“持续性与资本代价”：订单增长是否需要更多现金，周期利润能否正常化，回报是否受融资、客户或治理约束。资料齐备时用已有模型测算，不为每家公司默认构造概率和预测。

### 7. 价格与情景研究（适用时）

研究投资价值时取得对应时点价格、市值、净债务、股本和适用的盈利口径。先检查价格所隐含的要求，再与业务证据比较。市场共识需要明确来源和时点，没有一致预期数据不宣称预期差。

偏弱、基准、偏强情景的假设分别有历史或业务锚点；量价、毛利、产能、现金和融资相容。给敏感性与无法估计的部分，不机械统一加减10%。缺关键输入就保留估值缺口，不拿行业均值补成完整估值。不输出买卖指令。

### 8. 撰写与验收

围绕用户最关心的一项矛盾写成文章：先回答问题，再解释支持与反对证据，最后说明当前定位及改变判断的信号。比如公司点评解释“收入扩张为何没有等幅变成利润和现金”；基金比较解释“多赚的收益付出了什么回撤代价”；ETF评价解释“底层资产的差异与产品复制质量分别意味着什么”。按实际材料选择主线，不把这些例子套到所有标的。

需要改善论证与表达时，可阅读一篇相关真实点评，借鉴它提出的问题和证据组织方式，再用本次底稿独立写作。评论的专有数据、评级、推荐和因果解释不直接移用；转载同一底层来源不增加独立证据。已有证据足够就连贯交付，评论检索不设为每次研究的前置门槛。

删除重复结论与免责，无关明细移到附录；正文保留实际影响判断的限制，不把未知原因藏进通用免责声明。完整财务表、哈希与核验计数进入附录。按[深度研究交付标准](research-depth-standard.md)复查结论、缺口及研究层级，不能用格式或核验通过代替分析。

所有报告数字与底稿一致，证据链接可达，页码口径明确。批量报告检查重复段落是否真的适用每家公司；不能把“需要核查”全部搬到正文当作已完成的分析。更新保存新版本，保留首次判断及变化理由。

## 各类任务的分析主线

|任务|主线|关键限制|
|---|---|---|
|公司研究|实际业务 → 驱动及竞争 → 三表与分部 → 现金兑现 → 风险与反证 → 适用估值|缺少业务证据时交付财务专题，不冒称完整深研|
|基金或ETF研究|产品约束/指数 → 同口径业绩及风险 → 基准与同类 → 披露持仓/经理 → 费用和结构风险|季报持仓不还原真实交易；同类池说明范围|
|组合诊断|实际持仓 → 已知底层暴露 → 重叠与风险贡献 → 历史/情景 → 显式方案对照|没有交易记录不确认真实持有收益；情景不是未来最大回撤|
|公告事件|版本、主体和条件 → 经济影响路径 → 金额与时点 → 竞争解释 → 后续证据|消息情绪、政策关键词不直接成为经营受益结论|
|宏观/行业|官方所属期与版本 → 驱动和传导 → 多变量交叉验证 → 企业或资产的条件影响|相关性不是因果，全行业结论需要合理覆盖|
|研究复盘|首次问题和依据 → 新证据/更正 → 参数与口径变化 → 判断更新|事后材料不改写事前依据，旧结果不证明预测能力|

### 各模块评价要建立的判断

同一套“问题—判断—支持/反对证据—情景—反证—缺口”逻辑，按资产机制选择评价维度。以下是分析方法，不意味着已接通全部数据或新增执行器；不为每份报告默认跑所有模型。

|场景|先回答|再用什么证据检验|避免的替代结论|
|---|---|---|---|
|ETF|底层暴露是否合适，产品实现是否有效，交易成本是否经济|指数编制与集中、净值跟踪与偏离、费用/价差/折溢价时点、底层流动性|指数表现好不等于产品优质；市价不冒充净值；资金流代理不是真实现金流|
|组合|是否符合资金用途、期限、损失及流动性约束|目标与约束、已知敞口、风险贡献、历史/压力及调仓摩擦|低个股重叠不证明风险分散，历史最优不代表未来最优|
|公司|商业模式能否持续兑现现金；当前价格要求是否合理|实际业务量价成本、资本占用/配置、竞争、治理及估值敏感性|经营质量与价格吸引力分别判断；账表匹配不当点评|
|行业|供需与竞争怎样影响盈利，行业内部谁分化|行业边界、生命周期、库存/产能、价格传导及公司覆盖|政策支持不直接证明需求，行业中位数不外推全部公司|
|宏观|哪些增长/通胀/政策/流动性路径成立，哪些仍是假设|所属期/发布日期/修订、多变量、基准与替代情景、资产传导证据|单指标不自动确定周期，同期相关不证明因果，不预测确定涨跌|
|北交新股|公司和发行价是否合理，获配与现金占用结果怎样|经营定价、当期发行条款、配售率情景、资金时间账、首日涨幅假设与损失|数学获配能力不等于投资价值，事后价格不倒灌事前预测|
|债券/信用|何种现金可用于偿债，期限与利差补偿什么风险|现金可用性、债务到期、再融资、担保与顺位、信用及利率压力|账面现金不等于可偿债现金，不自设机构信用等级|
|转债|信用、正股与条款如何共同影响不对称风险|上述信用检查、正股与转股价值、溢价、强赎/回售/下修条件及实施状态|低价不一定安全，触发不等于执行，不套通用触发阈值|
|REITs|底层运营能否持续提供可分配现金|资产适用运营指标、资本开支、经营期限、负债及治理|分派率不是总收益，评估值不是成交价，预测分配不保证兑现|
|商品/期货|特定合约的供需、库存与结构风险如何|合约与交割规格、现货/基差、曲线、库存、保证金及移仓|现货收益不当期货持有收益，保证金不当最大损失|

基金详见[评价框架](fund-evaluation.md)。用户目标缺失时可交付结构性观察，不能捏造适配目标；关键证据不足时未回答维度单列，不用核验计数替代评价。不把完整归因、DCF或蒙特卡洛一律设为所有报告必备门槛；只有相应问题依赖它时才触发。

方法核查日期2026-10-07：参考[SEC ETF说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-24)、[CFA组合过程](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/portfolio-management-overview)、[CFA行业分析](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/industry-and-competitive-analysis)、[IFRS管理层评论](https://www.ifrs.org/issued-standards/list-of-standards/management-commentary-practice-statement-1/)、[IMF情景与不确定性](https://www.imf.org/en/news/articles/2025/05/07/sp050725-science-of-monetary-policy-in-emerging-markets-gita-gopinath)、[北交发行承销发布页](https://www.bse.cn/fxrz_list/200025384.html)、[上交所转债教育](https://edu.sse.com.cn/service/hotline/qa/c/5151728.shtml)和[REITs说明](https://www.sse.com.cn/reits/)。这些来源支持研究问题选择，不将教育资料、海外准则或专业方法当作境内当前强制规则；具体制度与标的仍按[适用依据](research-basis-standard.md)核对有效原文。未复制评级算法或机构专有评分。

具体调用继续使用[公司财报流程](company-report-workflow.md)、[研究模板](research-workflow.md)和[能力分工](shared-research-layers.md)。本流程是AI组织和验收约定，不宣称已有统一自动深研执行器。

## 完成状态与继续规则

获取、解析、计算、核验、导出分别说明状态。某个环节未完成，不得把整份研究描述为全部核验完成；也不丢弃其他成功产出。

继续研究时先读取已有输入与结果，复用身份、窗口和合格缓存。若参数、原始文件或算法版本改变，重算受影响部分并保存新版本。无需受影响的部分不重复执行。远程更正需要重新获取，固定快照无法自行知道网页已变化。

已接通的研究模板及其参数见[研究上下文与模板](research-workflow.md)。公司财报取数使用独立流水线，复核模板共享截止日、币种及来源版本；ETF收盘对照与组合贡献已有统一模板；其他ETF数据域、FOF自动取报及债券不由该封装自动覆盖。

## 交付验收

1. 命令与文档一致，输入示例可运行；错误路径保留清晰结果。
2. 至少用新标的实际运行新增计算链路，记录数据截止日；模拟测试与真实取数验收分别说明。
3. 原文核验展示匹配项、差异项、缺失项和页码，不以下载成功代替核验。
4. 复算关键公式；表格与报告数字一致，不能把半年度原文核验扩大为所有单季均已核验。
5. 导出文件可打开，表格无公式错误；报告先给可读发现，再给依据和本次局限。
6. 功能说明、安装副本和发布包内容一致；不把本地样本覆盖写成全市场承诺。

多场景研究按[26项执行映射](investment-research-scenarios.md)选择已有入口，未接通计算链路明确保留缺口。


## 延续研究时的选择

问“公司上下游是什么”：复用原文精读的产业链结构；逐环节给依据，缺失环节留空。客户、供应商名称与应用行业、采购品类分别表述。

问“前后季度变化多少”：复用跨期财务对照，从同一档案重算两期，利润现金流按单季、资产负债按期末。先检查单位、范围及重述，再解释变化。此结果不证明研究者在当时已经掌握这些数据。

问“两次研究为什么不同”：复用版本对照，核查登记对象、口径、来源和方法版本。缺计算记录、缺摘要或版本冲突不确认可比；参数改变不能称为纯市场变化。

三类问题可以在一次对话中串联，但不能互相替代验收：引句定位不是经营判断已证实，数值差额不是因果归因，版本一致不是全部资料已核验。

## 政策问题的资料顺序
先明确国家、行业、所问时点与政策对象，再获取已公开原件并记录公布时间。使用研报精读的 policyAnalysis 定位适用范围、生效条款、条件和风险。公告原文未写明生效日或缺少后续版本时，不以公布日补填，不确认当前有效。政策对经营或资产的影响作为待验证解释；需要指标与反证，不从政策关键词推导买卖结论。


## 行情与财报窗口

行情起始日和财务报告期起始日可以不同。查询近一个月行情时，若同时研究财务，显式指定financialStart（例如前一年起），否则同一窗口可能没有报告期落入。每个取数组件记录实际请求区间；空结果先核对窗口，不能判为公司未披露财报。用户指定的窄区间不自动扩大，不将更早财报混入该区间。


## 研究交付与采集维护分开

普通评价请求先确定必须回答的问题及其必要证据。已有证据能够支持的判断连贯写入报告；缺口分别标为会使结果错误、会限制特定结论、或属于后续增强。认错主体、错数和关键口径冲突必须先处理；缺少归因或完整事件等资料，只限制依赖它的结论。不要将一次基金评价扩成无限资料修补，也不要让用户逐项确认内部步骤。主报告先讲判断、核心矛盾及支持/反对证据，技术核验明细与维护进度放在独立底稿。维护任务仍保留原始范围与未完成要求，不因当前报告可交付便将整个模块标完成。
